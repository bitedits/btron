Desktop: Desktop Shell, Workbench & Mobile UI

Comprehensive C99 specification for the B-System desktop shell environment: root background compositor, Workbench event distribution, Haiku-style Tracker deskbar, Global Menu Bar, and the NTT DoCoMo FOMA mobile UI toolkit.

1. Architecture & Shell Topology

The Desktop subsystem coordinates all visual layers lying outside individual application client viewports. It implements a unified shell architecture that adapts dynamically to both high-resolution desktop displays (1920×1080) and portrait mobile screens (480×640 VGA): 

 ┌────────────────────────────────────────────────────────────────────────┐
 │ Global Menu Bar (トップメニュー)                                          │ ◄── Height: 24px
 ├────────────────────────────────────────────────────────────────────────┤

 │   │ Active Window (WND)  │             │ Tracker Deskbar (タスクトラッカー) │   │
 │   └──────────────────────┘             └───────────────────────────┘   │
 └────────────────────────────────────────────────────────────────────────┘
  • Desktop Compositor (desktop.c): Manages the root framebuffer, desktop background patterns (classic B-TRON Teal #008080), and bare-metal cursor rendering.
  • Workbench Coordinator (workbench.c): Directs mouse, keyboard, and touch events between the root shell, active window, and deskbar overlays.
  • Tracker Deskbar (tracker.c): Low-latency root application launcher and live window tracker modeled after Haiku / BeOS Deskbar.
  • Global Menu Bar (global_menu.c): System-wide menu bar providing fast access to standard cabinets, accessories, and power management.

2. Data Structures & Types

Desktop Context (BTRON_DESKTOP)

Defined in include/btron/desktop.h:

typedef struct {
    H      width;      /* Total screen pixel width */
    H      height;     /* Total screen pixel height */
    GDEV   *screen;    /* Master display framebuffer device context */
    BOOL   running;    /* Execution flag for main desktop loop */
} BTRON_DESKTOP;

3. μBTRON-FOMA Mobile UI Toolkit

For portrait handheld devices (480×640 VGA), the desktop subsystem incorporates a dedicated mobile compositor (desktop_mobile.c / workbench_mobile.c) adhering strictly to NASA JPL Rule 3:

Geometry Constant Pixel Value Description
FOMA_SCREEN_W 480 VGA portrait screen width.
FOMA_SCREEN_H 640 VGA portrait screen height.
FOMA_STATUS_BAR_H 32 Top status bar showing signal, 3G data, battery, and clock.
FOMA_TITLE_BAR_H 36 Screen title header bar.
FOMA_SOFTKEY_BAR_H 38 Bottom softkey action bar ([Left], [Center/Menu], [Right/Back]).

4. Desktop API Function Reference

init_desktop ER

Initializes the desktop compositor, window manager, and root background for the given dimensions.

ER init_desktop(H width, H height);
run_desktop_loop void

Enters the master BTRON desktop event dispatch loop until a shutdown signal is received.

void run_desktop_loop(void);
tracker_init void

Initializes the Haiku-style Deskbar / Tracker root menu, positioning the toggle button at the top-right.

void tracker_init(H screen_width);
foma_show_about_dialog void

Activates the rich mobile About modal dialog displaying application branding, metadata, and 5HT attribution.

void foma_show_about_dialog(const char *app_name, const char *jp_title, const char *desc, const char *attribution);

5. Canonical Implementation Examples

The following example demonstrates launching the desktop shell on a physical or virtual framebuffer: 

#include <btron/desktop.h>
#include <btron/workbench.h>

int main(void) {
    /* 1. Initialize desktop environment at 1024x768 */
    init_desktop(1024, 768);

    /* 2. Initialize Workbench menus and Deskbar tracker */
    workbench_init(1024);

    /* 3. Run master event loop */
    run_desktop_loop();

    return 0;
}
