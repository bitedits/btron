Graphics: Display Primitives & 2D Engine

Formal C99 specification for the Display Primitives (DP) engine: GDEV graphic device abstraction, 2D vector primitives, hardware clipping, raster operations (ROP), and pointer capture management.

1. Architecture & Pipeline

The Graphics subsystem provides the foundational rendering engine for B-System. Designed according to the cleanroom BTRON 3.20 specification, all drawing operations target an abstract graphic device descriptor: GDEV.

1.1 Coordinate Space & Clipping Semantics

B-System uses a top-left origin pixel coordinate space where $(0, 0)$ is the top-left pixel. Coordinate values are signed 16-bit integers (H):

  • Horizontal Coordinate ($X$): Increases from left to right $[0, \text{width} - 1]$.
  • Vertical Coordinate ($Y$): Increases from top to bottom $[0, \text{height} - 1]$.
  • Clipping Rect (clip): Inclusive of left and top, exclusive of right and bottom. Primitives automatically clip against these bounds with zero out-of-bounds writes.

2. Data Structures & Types

Graphic Device Descriptor (GDEV)

Defined in include/btron/dp.h:

typedef struct {
    H      width;      /* Total canvas width in pixels */
    H      height;     /* Total canvas height in pixels */
    UW     is_vram;    /* 1 if hardware VRAM frame buffer, 0 if memory buffer */
    COLOR  *pixels;    /* Direct pointer to 32-bit ARGB pixel buffer */
    RECT   clip;       /* Current active clipping rectangle */
} GDEV;
Field Type Offset Description
width H (int16_t) 0 Canvas pixel width. Must be strictly positive.
height H (int16_t) 2 Canvas pixel height. Must be strictly positive.
is_vram UW (uint32_t) 4 Flag designating direct VRAM mapping versus allocated heap/static backing.
pixels COLOR* 8 Pointer to continuous linear array of width * height 32-bit ARGB words.
clip RECT 16 Active bounding box for clipping rasterization operations.

Macro Value Boolean Logic Operational Effect
ROP_COPY 0 $D = S$ Direct pixel overwrite (Standard transfer).
ROP_OR 1 $D = D \mid S$ Additive raster combination.
ROP_XOR 2 $D = D \oplus S$ Invertible rubber-banding and selection cursors.
ROP_AND 3 $D = D \ \& \ S$ Masked transparency filtering.
ROP_INVERT 4 $D = \sim D$ Bitwise color inversion.

4. Display Primitives API Reference

opn_dev GDEV*

Allocates and initializes an off-screen graphic device context with internal pixel memory.

GDEV* opn_dev(H w, H h);
Parameter Type Description
w H Width in pixels (must be > 0).
h H Height in pixels (must be > 0).
Returns Pointer to initialized GDEV, or NULL on allocation failure.
opn_dev_vram GDEV*

Constructs a graphic device context directly bound to an external physical or virtual VRAM frame buffer.

GDEV* opn_dev_vram(H w, H h, COLOR *vram_buffer);
cls_dev void

Closes and frees resources associated with a GDEV device. If is_vram == 0, frees the pixel backing store.

void cls_dev(GDEV *dev);
set_clip void

Constrains subsequent rasterization routines to the intersection of the device dimensions and the specified rectangle.

void set_clip(GDEV *dev, const RECT *clip);
drw_lin ER

Renders a 1-pixel solid vector line between two points using Bresenham's line algorithm with integer arithmetic.

ER drw_lin(GDEV *dev, H x1, H y1, H x2, H y2);
fill_rec ER

Fills a solid axis-aligned rectangle with the specified color, clipped against dev->clip.

ER fill_rec(GDEV *dev, const RECT *r, COLOR col);
drw_rec ER

Draws a 1-pixel hollow bounding frame for the specified rectangle.

ER drw_rec(GDEV *dev, const RECT *r);
sdl_set_mouse_grab / sdl_toggle_mouse_grab void

Controls host mouse cursor capture (QEMU-style ^G / Ctrl+G grab and release).

void sdl_set_mouse_grab(BOOL grabbed);
void sdl_toggle_mouse_grab(void);
BOOL sdl_is_mouse_grabbed(void);

5. Canonical Implementation Examples

The following example demonstrates creating an offscreen buffer, drawing a classic 3D beveled plate, and applying clipping: 

#include <btron/dp.h>

void render_beveled_box(GDEV *dev, H x, H y, H w, H h) {
    RECT outer = { x, y, x + w, y + h };
    
    /* 1. Base button surface in classic light gray */
    fill_rec(dev, &outer, COLOR_LTGRAY);

    /* 2. Top and left edges in white (highlight) */
    drw_lin(dev, x, y, x + w - 1, y);         /* Top edge */
    drw_lin(dev, x, y, x, y + h - 1);         /* Left edge */

    /* 3. Bottom and right edges in dark gray (shadow) */
    drw_lin(dev, x, y + h - 1, x + w, y + h - 1); /* Bottom edge */
    drw_lin(dev, x + w - 1, y, x + w - 1, y + h); /* Right edge */
}
