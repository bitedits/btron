HMI: Human-Machine Interface Specification

Comprehensive C99 developer specification for the official TRON Human-Machine Interface (HMI) standard library: physical control emulation, rotary volumes, step selectors, bar meters, Enableware tactile indicators, and industrial panel containers.

1. The TRON HMI Design Philosophy

The HMI subsystem implements the canonical TRON Human-Machine Interface Specification designed by Dr. Ken Sakamura. Unlike standard desktop widget toolkits that favor arbitrary rectangular buttons, TRON HMI faithfully models the physical ergonomics, tactile affordances, and safety invariants of real-world electronic instrumentation:

  • Consistent Operating Procedures: Clear operational distinction between Touch Edge (activation on press down) and Release Edge (activation on button release).
  • Standard Triad Group: Universal grouping of Cancel (left), Default (center), and Start/Execute (right) controls.
  • Enableware Support: Built-in tactile bumps (bocchi / ボッチ) on key controls to assist visually impaired operators and touch typing.
  • Three-Color Status Semantics: Unambiguous industrial state signals — Green (Normal/Safe), Yellow/Amber (Standby/Caution), and Red (Stop/Alert).

2. Control Primitives & Types

HMI Control Types (HMI_CTRL_TYPE)

Defined in include/btron/hmi.h:

Enum Constant Physical Metaphor Operational Behavior
HMI_TYPE_PUSH_SWITCH Momentary Push Button Activates temporarily while pressed; snaps back immediately upon release.
HMI_TYPE_TOGGLE_SWITCH Push-Lock / Alternate Switch Toggles state on each press; remains mechanically depressed until pressed again.
HMI_TYPE_STANDARD_TRIAD Safety Triad Group Standardized Cancel / Default / Execute button cluster.
HMI_TYPE_UPDOWN_SELECTOR Digital Step Stepper Dual-arrow up/down discrete value incrementor/decrementor.
HMI_TYPE_RADIO_SELECTOR Exclusive Mechanical Interlock Mutually exclusive option selection (radio button matrix).
HMI_TYPE_ROTARY_SELECTOR Multi-position Rotary Switch Rotary knob selecting discrete functional modes (e.g. Off / Low / Med / High).
HMI_TYPE_SLIDER_VOLUME Linear Slide Potentiometer Continuous vertical or horizontal fader knob for volume and brightness.
HMI_TYPE_DIAL_VOLUME Rotary Analog Potentiometer Circular continuous dial knob with angle-to-value transformation.
HMI_TYPE_BAR_METER LED Bargraph VU Meter Multi-segment visual level indicator with green/yellow/red bands.
HMI_TYPE_STATUS_LED 3-Color Pilot Lamp Status indicator (Green, Yellow, Red, or Off).
HMI_TYPE_UNIVERSAL_PAD TRON Universal Controller Standardized directional keypad with center execute and auxiliary buttons.

Control Descriptor (HMI_CTRL)

typedef struct HMI_CTRL {
    ID               id;           /* Control identifier within host panel */
    HMI_CTRL_TYPE    type;         /* Widget type category */
    RECT             bounds;       /* Layout position relative to panel */
    UW               flags;        /* State flags (ACTIVE, FOCUSED, PRESSED, ENABLEWARE) */
    HMI_TRIGGER_MODE trigger;      /* TOUCH_EDGE or RELEASE_EDGE */
    char             label[64];    /* Caption or description string */
    char             unit[16];     /* Value measurement unit (e.g. dB, %, rpm) */

    /* Values & Bounds */
    int              val;          /* Current integer state value */
    int              min_val;      /* Minimum permissible value */
    int              max_val;      /* Maximum permissible value */
    int              step;         /* Discrete step increment */

    /* Options for Selectors */
    int              num_options;  /* Count of discrete selector items */
    const char       *options[16]; /* Array of option text labels */

    /* Visual Overrides */
    HMI_LED_COLOR    led_color;    /* LED state if applicable */
} HMI_CTRL;

3. Panel Container Architecture

An HMI_PANEL acts as the composite instrument board containing multiple controls. It handles layout rendering, mouse tracking, and keyboard tab focus navigation: 

typedef struct HMI_PANEL {
    RECT             bounds;       /* Panel boundary */
    int              ctrl_count;   /* Number of controls mounted on panel */
    HMI_CTRL         ctrls[32];    /* Static control array (NASA JPL Rule 3) */
    int              focused_idx;  /* Index of currently focused control */
    HMI_CALLBACK     on_change;    /* Value mutation notification callback */
} HMI_PANEL;

4. HMI API Function Reference

hmi_init_panel void

Initializes an HMI instrument panel structure with zero post-boot heap allocations.

void hmi_init_panel(HMI_PANEL *panel, const RECT *bounds, HMI_CALLBACK cb);
hmi_add_switch HMI_CTRL*

Mounts a momentary or alternate toggle switch onto the target panel.

HMI_CTRL* hmi_add_switch(HMI_PANEL *panel, ID id, const char *label, const RECT *r, BOOL is_toggle);
hmi_add_volume HMI_CTRL*

Mounts a slide or rotary volume knob with min/max calibration and engineering units.

HMI_CTRL* hmi_add_volume(HMI_PANEL *panel, ID id, const char *label, const RECT *r, int min_val, int max_val, int init_val, const char *unit, BOOL is_dial);
hmi_draw_panel void

Renders the entire instrument panel, beveled borders, control states, and Enableware tactile markers into the target graphic device.

void hmi_draw_panel(const HMI_PANEL *panel, GDEV *dev);

5. Canonical Implementation Examples

The following example demonstrates setting up an industrial audio mixer instrument panel with slider volumes and level meters: 

#include <btron/hmi.h>

static void on_mixer_change(HMI_CTRL *ctrl, HMI_PANEL *panel, void *user_data) {
    (void)panel; (void)user_data;
    /* React to slider volume adjustments */
    if (ctrl->id == 101) {
        set_master_volume_gain(ctrl->val);
    }
}

void setup_audio_panel(HMI_PANEL *panel) {
    RECT panel_bounds = { 10, 10, 320, 240 };
    hmi_init_panel(panel, &panel_bounds, on_mixer_change);

    /* Add Master Slider Volume */
    RECT vol_rect = { 30, 40, 70, 180 };
    hmi_add_volume(panel, 101, "Master", &vol_rect, 0, 100, 75, "%", FALSE);

    /* Add Power Toggle Switch */
    RECT pwr_rect = { 100, 40, 200, 75 };
    hmi_add_switch(panel, 102, "Amplifier Power", &pwr_rect, TRUE);
}
