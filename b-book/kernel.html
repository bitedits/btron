Kernel: Sakamura T-Kernel 2.0 Specification

Comprehensive full-scope developer reference for the B-System real-time operating system kernel: preemptive priority task scheduling, inter-task synchronization (semaphores, event flags, mailboxes, mutexes, message buffers, rendezvous ports), dynamic and fixed memory pools, cyclic/alarm handlers, and device management.

1. Kernel Architecture & Scheduling Model

The Kernel subsystem provides the deterministic, hard real-time operating system foundation for B-System, based on the official Sakamura T-Kernel 2.0 (TRON Architecture) specification:

1.1 Real-Time Scheduling Rules

  • Preemptive Priority Scheduling: Highest-priority ready task runs immediately. Up to 140 distinct priority levels (1 = Highest, 140 = Lowest).
  • Round-Robin Support: Ready queue rotation within the same priority level via tk_rot_rdq().
  • Priority Inversion Protection: Mutexes implement Priority Inheritance and Priority Ceiling protocols to prevent unbounded priority inversion.
  • Deterministic Latency: Zero dynamic heap allocations in kernel paths after bootstrap (NASA JPL Rule 3 compliance).

2. Data Structures & Creation Packets

All T-Kernel 2.0 object creation system calls take a pointer to a specialized creation packet structure:

Task Creation Packet (T_CTSK)

Defined in include/tk/syscall.h:

typedef struct t_ctsk {
    VP     exinf;       /* Extended information / user context */
    ATR    tskatr;      /* Task attributes (TA_HLNG, TA_USERSTACK, TA_DSNAME) */
    FP     task;        /* Task execution entry point function pointer */
    PRI    itskpri;     /* Initial task priority (1 to 140) */
    SZ     stksz;       /* Stack size in bytes */
    SZ     sstksz;      /* System stack size in bytes */
    VP     stk;         /* User stack address (if TA_USERSTACK) */
    UB     dsname[8];   /* Debugger / object name string */
} T_CTSK;

Semaphore Creation Packet (T_CSEM)

typedef struct t_csem {
    VP     exinf;       /* Extended information */
    ATR    sematr;      /* Semaphore attributes (TA_TFIFO, TA_TPRI, TA_FIRST) */
    INT    isemcnt;     /* Initial resource semaphore count */
    INT    maxsem;      /* Maximum resource count capacity */
    UB     dsname[8];   /* Diagnostic object name */
} T_CSEM;

Event Flag Creation Packet (T_CFLG)

typedef struct t_cflg {
    VP     exinf;       /* Extended information */
    ATR    flgatr;      /* Event flag attributes (TA_TFIFO, TA_TPRI, TA_WMUL) */
    UINT   iflgptn;     /* Initial 32-bit bitmask pattern */
    UB     dsname[8];   /* Diagnostic object name */
} T_CFLG;

Mutex Creation Packet (T_CMTX)

typedef struct t_cmtx {
    VP     exinf;       /* Extended information */
    ATR    mtxatr;      /* Mutex attributes (TA_TFIFO, TA_TPRI, TA_INHERIT, TA_CEILING) */
    PRI    ceilpri;     /* Ceiling priority limit (if TA_CEILING) */
    UB     dsname[8];   /* Diagnostic object name */
} T_CMTX;

3. Task Management System Calls

System Call Return Type Parameters Description
tk_cre_tsk ID const T_CTSK *pk_ctsk Creates a new task in DORMANT state and returns its unique task ID.
tk_del_tsk ER ID tskid Deletes a task in DORMANT state, freeing its control block and stack.
tk_sta_tsk ER ID tskid, INT stacd Starts a task, transitioning it from DORMANT to READY.
tk_ext_tsk void void Terminates the invoking task, transitioning it to DORMANT.
tk_exd_tsk void void Terminates and automatically deletes the invoking task.
tk_ter_tsk ER ID tskid Forcibly terminates another target task into DORMANT state.
tk_chg_pri ER ID tskid, PRI newpri Changes task priority dynamically (1 to 140, or TPRI_INI).
tk_rot_rdq ER PRI tskpri Rotates the ready queue for the given priority level (round-robin step).
tk_rel_wai ER ID tskid Forcibly releases target task from WAITING state with ER_RLWAI.
tk_slp_tsk ER TMO tmout Puts invoking task to sleep until awakened via tk_wup_tsk or timeout.
tk_wup_tsk ER ID tskid Wakes up a sleeping task or queues a wakeup request.
tk_ref_tsk ER ID tskid, T_RTSK *pk_rtsk Queries current task status, execution state, priority, and wait factors.

4. Synchronization & Communication Primitives

4.1 Semaphores

tk_cre_sem / tk_sig_sem / tk_wai_sem ID / ER

Counting semaphores for mutual exclusion and shared resource capacity tracking.

ID tk_cre_sem(const T_CSEM *pk_csem);
ER tk_sig_sem(ID semid, INT cnt);
ER tk_wai_sem(ID semid, INT cnt, TMO tmout);
ER tk_del_sem(ID semid);

4.2 Event Flags

tk_cre_flg / tk_set_flg / tk_clr_flg / tk_wai_flg ID / ER

32-bit pattern event flags supporting TWF_ANDW and TWF_ORW multi-bit condition matching.

ID tk_cre_flg(const T_CFLG *pk_cflg);
ER tk_set_flg(ID flgid, UINT setptn);
ER tk_clr_flg(ID flgid, UINT clrptn);
ER tk_wai_flg(ID flgid, UINT waiptn, UINT wfmode, UINT *p_flgptn, TMO tmout);

4.3 Mutexes

tk_cre_mtx / tk_loc_mtx / tk_unl_mtx ID / ER

Recursive mutual exclusion lock with Priority Inheritance (TA_INHERIT) and Priority Ceiling (TA_CEILING).

ID tk_cre_mtx(const T_CMTX *pk_cmtx);
ER tk_loc_mtx(ID mtxid, TMO tmout);
ER tk_unl_mtx(ID mtxid);
ER tk_del_mtx(ID mtxid);

4.4 Mailboxes & Message Buffers

System Call Primitive Operational Semantics
tk_snd_mbx / tk_rcv_mbx Mailbox (MBX) Asynchronous pointer-based message passing through priority/FIFO mail queues.
tk_snd_mbf / tk_rcv_mbf Message Buffer (MBF) Byte-stream variable-length message copy into a bounded ring buffer.
tk_cal_por / tk_acp_por Rendezvous Port (POR) Synchronous client-server bidirectional rendezvous handshake with reply.

5. Memory Pool Management

  • Variable-Size Memory Pools (MPL): tk_cre_mpl(), tk_get_mpl(), tk_rel_mpl(). Allocates arbitrary byte lengths from a designated heap with best-fit / first-fit coalescing.
  • Fixed-Size Memory Pools (MPF): tk_cre_mpf(), tk_get_mpf(), tk_rel_mpf(). High-speed $O(1)$ constant-time allocation of fixed-size blocks from a bitmap-tracked pool.

6. Time Management & Cyclic Handlers

tk_get_tim / tk_dly_tsk / tk_cre_cyc ER

Microsecond system clock time, task delay timers, and periodic cyclic execution handlers.

ER tk_get_tim(SYSTIM *pk_tim);
ER tk_set_tim(const SYSTIM *pk_tim);
ER tk_dly_tsk(RELTIM dlytim);
ID tk_cre_cyc(const T_CCYC *pk_ccyc);
ER tk_sta_cyc(ID cycid);
ER tk_stp_cyc(ID cycid);

7. Device Management & Subsystem Registry

System Call Function Description
tk_opn_dev Device Open Opens registered device driver (e.g. "vda", "console").

8. Canonical Implementation Examples

The following example demonstrates creating a worker task, synchronizing execution via an event flag, and scheduling a periodic cyclic timer: 

#include <tk/tkernel.h>

#define FLAG_WORK_READY  (1 << 0)
#define FLAG_WORK_DONE   (1 << 1)

static ID s_flgid;

/* Worker Task Entry Point */
static void worker_task(INT stacd, VP exinf) {
    (void)stacd; (void)exinf;
    UINT flgptn = 0;

    while (1) {
        /* Wait for WORK_READY event flag */
        tk_wai_flg(s_flgid, FLAG_WORK_READY, TWF_ANDW | TWF_CLR, &flgptn, TMO_FEVR);

        /* Perform real-time processing */
        do_work();

        /* Signal completion */
        tk_set_flg(s_flgid, FLAG_WORK_DONE);
    }
}

void initialize_kernel_subsystem(void) {
    /* 1. Create synchronization event flag */
    T_CFLG cflg = {
        .exinf = NULL,
        .flgatr = TA_TFIFO | TA_WMUL,
        .iflgptn = 0,
        .dsname = "WORKFLG"
    };
    s_flgid = tk_cre_flg(&cflg);

    /* 2. Create worker task with priority 10 */
    T_CTSK ctsk = {
        .exinf = NULL,
        .tskatr = TA_HLNG | TA_DSNAME,
        .task = (FP)worker_task,
        .itskpri = 10,
        .stksz = 4096,
        .dsname = "WORKER"
    };
    ID tskid = tk_cre_tsk(&ctsk);

    /* 3. Start task */
    tk_sta_tsk(tskid, 0);
}
