Settings: Configuration & Control Panel

Comprehensive C99 specification for the B-System configuration management framework: modular Control Panel applets, real-time theme propagation without reboots, dirty state synchronization, and terminal emulation profiles.

1. Control Panel Architecture

The Settings subsystem provides an extensible, unified framework for managing system-wide operational parameters. In alignment with BTRON principles, all settings are managed via dedicated Real Objects grouped inside the Settings Cabinet (設定キャビネット): 

 [ Settings Cabinet (設定キャビネット) ]
            │
            ├── [ Appearance (外観設定) ]  ──► Themes, Bevel Styles, Icon Metrics
            ├── [ Desktop (デスクトップ) ] ──► Background Colors, Grid Spacings
            ├── [ Display (画面表示) ]    ──► Resolution, Color Depth, Refresh
            ├── [ Input (入力環境) ]       ──► Key Repeat, Acceleration, TIP IME
            ├── [ Language (言語環境) ]   ──► Locale, TRON Planes, Tibetan EWTS
            ├── [ Terminal (端末設定) ]   ──► ANSI Colors, Baud Rates, Fonts
            └── [ Sound (音響設定) ]      ──► Master Volumes, Alert Bells

3. Configuration Lifecycle & Broadcast

Settings applets follow a strict non-modal, transactional state machine:

  1. Initial State: Reads active settings from the persistent Real Object storage record.
  2. Mutation (is_dirty): Modifying UI switches or sliders sets is_dirty = TRUE and enables the [適用 (Apply)] button.
  3. Application & Broadcast: Clicking Apply flushes parameters to disk and broadcasts a global refresh event (redraw_all_windows()) across all running tasks without requiring an OS restart.
  4. Reversion: The [標準 (Default)] button immediately restores factory-calibrated safety values.

5. Canonical Implementation Examples

The following example demonstrates opening a settings panel and wiring the apply callback to update the global menu styling: 

#include <btron/settings.h>
#include <btron/app_menu.h>

void apply_custom_theme(APP_MENU_STYLE style) {
    /* 1. Update global menu style */
    app_menu_set_global_style(style);

    /* 2. Broadcast repaint to all active windows */
    redraw_all_windows();
}
