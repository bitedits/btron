Tip: Text Input Primitives & Multilingual IME

Formal C99 specification for the B-System Text Input Primitives (TIP) subsystem: Input Front-End (IFE) engine, deterministic finite automaton (DFA) state machines, Kana-Kanji conversion (Mozc), Tibetan Wylie phonetics, and 16-plane TRON-Code multilingual typography.

1. Architecture & Deterministic State Machine

The Tip subsystem (Text Input Primitives) is the universal multilingual text composition and input method engine for B-System. Following the cleanroom BTRON 3.20 specification, TIP acts as a system-level filter between low-level keyboard scan codes and application text widgets.

1.1 TIP DFA State Machine

Input composition is governed by a formal 4-state Deterministic Finite Automaton (DFA): 

                     Direct ASCII / Pass-through
                 ┌────────────────────────────────┐
                 │                                │
                 ▼                                │
         ┌───────────────┐   Alphanumeric Keystroke
         │ TIP_STATE_    │ ───────────────────────► ┌───────────────┐
         │     IDLE      │                          │  TIP_STATE_   │
         └───────────────┘ ◄─────────────────────── │    PRECOMP    │
                 ▲           Backspace to Empty     └───────────────┘
                 │                                          │
                 │ Commit                                   │ Space / Tab (Convert)
                 │                                          ▼
         ┌───────────────┐   Up / Down / Tab Arrow  ┌───────────────┐
         │  TIP_STATE_   │ ◄─────────────────────── │  TIP_STATE_   │
         │ CANDIDATE_SEL │ ───────────────────────► │  CONVERTING   │
         └───────────────┘   Return (Select Item)   └───────────────┘

2. Supported Multilingual Input Modes

Mode Constant Enum Value Target Script & Encoding Composition Engine
TIP_MODE_ASCII 0 Standard ISO 8859-1 / ASCII Direct keystroke passthrough to active focus window.
TIP_MODE_HIRAGANA 1 Japanese Hiragana (TRON Plane 1 / JIS) Romaji → Hiragana phonetics + Mozc statistical KKC dictionary.
TIP_MODE_KATAKANA 2 Japanese Katakana (TRON Plane 1 / JIS) Direct Katakana transliteration + loanword dictionary.
TIP_MODE_TIBETAN 3 Classical Tibetan (Jomolhari Unicode) EWTS Wylie phonetics with automatic subjoined consonant stacking.

3. Data Structures & Contexts

Candidate Entry Structure (TIP_CANDIDATE)

Defined in include/btron/tip.h:

typedef struct {
    char value[64];       /* Converted Kanji / Tibetan term in UTF-8/TRON-Code */
    char annotation[64];  /* Semantic grammatical category (e.g. [名詞], [固有名詞]) */
    int  cost;            /* Statistical n-gram transition penalty */
} TIP_CANDIDATE;

Clause Structure (TIP_CLAUSE)

typedef struct {
    char           reading[64];          /* Phonetic reading (Yomi) */
    char           converted[64];        /* Active converted phrase */
    TIP_CANDIDATE  candidates[16];       /* List of candidate translations */
    int            num_candidates;       /* Number of valid candidates in array */
    int            selected_candidate;   /* Current highlighted candidate index (0-based) */
} TIP_CLAUSE;

Composition Context (TIP_CONTEXT)

typedef struct {
    TIP_INPUT_MODE mode;                 /* Current script input mode */
    TIP_DFA_STATE  state;                /* Active DFA machine state */
    char           romaji_buf[256];      /* Raw ASCII keystroke buffer */
    int            romaji_len;           /* Byte length of raw buffer */
    char           reading_buf[256];     /* Transliterated phonetic buffer */
    int            reading_len;          /* Byte length of reading */
    TIP_CLAUSE     clauses[32];          /* Parsed bunsetsu clauses */
    int            num_clauses;          /* Total clause segments */
    int            active_clause;        /* Index of clause currently undergoing focus */
    PNT            caret_pos;            /* Screen coordinate for candidate popup anchor */
    BOOL           candidate_window_visible; /* Floating candidate popup visibility */
} TIP_CONTEXT;

4. TRON-Code Multilingual Typography Engine

The B-System typography engine (include/btron/troncode.h) provides multi-plane character rendering without code-page switching:

  • 16 Planes Structure: Supports up to $16 \times 65,536 = 1,048,576$ distinct character codes.
  • Plane 1: JIS X 0208 / JIS X 0213 Japanese Kanji, Hiragana, Katakana.
  • Plane 2: Classical Chinese / Dai Kan-Wa Jiten historic variants.
  • Plane 9: Classical Tibetan Buddhist canon (Jomolhari font rasterizer).

5. TIP API Function Reference

tip_init void

Initializes the TIP composition engine, zeroes buffers, and binds the Mozc dictionary lookup tables.

void tip_init(void);
tip_process_key BOOL

Feeds a raw keyboard event into the TIP DFA. Returns TRUE if TIP consumed the key, or FALSE if it should pass to the application.

BOOL tip_process_key(UW key, uint16_t mod, char *out_commit, int max_commit);
Parameter Type Description
key UW Virtual key code or ASCII character.
mod uint16_t Key modifiers (Shift, Ctrl, Alt).
out_commit char* Buffer receiving finalized string if the key caused a commit.
max_commit int Capacity of the commit buffer in bytes.
tip_get_context const TIP_CONTEXT*

Returns a read-only pointer to the active TIP composition state for custom rendering.

const TIP_CONTEXT* tip_get_context(void);
drw_tc_string ER

Renders a multilingual UTF-8 or TRON-Code string into the target graphic device with subpixel anti-aliasing.

ER drw_tc_string(GDEV *dev, H x, H y, const char *str, COLOR fg, COLOR bg);

6. Canonical Implementation Examples

The following example demonstrates routing keystrokes through the TIP engine in an application event handler: 

#include <btron/tip.h>
#include <btron/wnd.h>

void my_app_key_handler(WND *wnd, const EVT *evt) {
    char commit_buf[128] = {0};

    /* 1. Feed event into TIP IME */
    BOOL handled = tip_process_key(evt->key, evt->mod, commit_buf, sizeof(commit_buf));

    /* 2. Check if a string was committed */
    if (commit_buf[0] != '\0') {
        insert_text_into_document(wnd, commit_buf);
    }

    /* 3. If TIP is composing, trigger window repaint for pre-edit underline */
    if (handled) {
        inval_wnd(wnd);
    }
}
