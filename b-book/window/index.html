Window: Window Manager, Events & Menus

Formal C99 specification for the Sakamura Window Manager (WND), sliding tab geometry, event distribution loops (EVT), fluid BeOS-style application menu bars, and multi-form-factor desktop/mobile viewports.

1. Architecture & Geometry

The Window subsystem governs all graphical viewport management, z-order stacking, compact sliding tabs, and user input dispatching in B-System.

1.1 Frame vs. Client Coordinate Geometry

 ┌────────────────────────────────────────────────────────┐
 │ [X]  Document Title               [Tab]            [-] │  ◄── Window Frame (bounds)
 ├────────────────────────────────────────────────────────┤
 │ File(F)   Edit(E)   View(V)   Help(H)                  │  ◄── Application Menu Bar
 ├────────────────────────────────────────────────────────┤
 │                                                        │
 │                   Client Area (client)                 │  ◄── (0, 0) relative client space
 │                                                        │
 └────────────────────────────────────────────────────────┘
  • Outer Bounds (bounds): Window boundary in root screen space, including 3D chrome borders, title bar, and drop shadows.
  • Client Area (client): Interior viewport dedicated to application content. In bordered desktop mode, client.top = bounds.top + 26 and client.left = bounds.left + 4. In borderless mobile mode, client.left = 0 and client.top = 0.
  • Compact Sliding Tab: Authentic Cho-Kanji draggable title tab. Its horizontal position is defined by tab_offset_x, enabling dense overlapping window stacks.

2. Data Structures & Types

Window Descriptor Structure (WND)

Defined in include/btron/wnd.h:

typedef struct WND {
    ID    id;                       /* Unique window object identifier */
    char  pad0[12];                 /* 12-byte padding for 16-byte title alignment */
    char  title[64];                /* Window title string */
    RECT  bounds;                   /* Absolute screen frame bounding box */
    RECT  client;                   /* Content client area rectangle */
    UW    attr;                     /* Window attribute bitmask (WND_ATTR_*) */
    BOOL  visible;                  /* Visibility flag */
    BOOL  focused;                  /* Topmost active focus state */
    H     tab_offset_x;             /* Horizontal offset of sliding tab */
    H     tab_width;                /* Computed tab width in pixels */
    GDEV  *dev;                     /* Graphic device context for client area */
    void (*paint)(struct WND *wnd, GDEV *dev);           /* Repaint callback */
    void (*event_handler)(struct WND *wnd, const EVT *evt); /* Event callback */
    void (*destroy)(struct WND *wnd);                    /* Teardown callback */
    VW    user_data;                /* Opaque pointer to application instance */
    struct WND *next;               /* Z-order next lower window */
    struct WND *prev;               /* Z-order next higher window */
} WND;

Window Attribute Bitmasks

Macro Constant Bit Value Description
WND_ATTR_TITLE 1 << 0 Renders top title bar.
WND_ATTR_CLOSE 1 << 1 Renders top-left [X] close widget.
WND_ATTR_MAX 1 << 2 Enables window maximize / zoom widget.
WND_ATTR_RESIZE 1 << 3 Enables bottom-right corner resize widget.
WND_ATTR_BORDER 1 << 4 Renders 3D beveled outer frame border.
WND_ATTR_SLIDING_TAB 1 << 6 Enables draggable compact sliding tab header.

3. Application Menu Subsystem

The B-System menu engine (include/btron/app_menu.h) provides unified, deduplicated in-window menu bars featuring BeOS fluid hover tracking, hot header gliding, dynamic mnemonics (Alt+Letter), 10-key numeric accelerators (1..9), and runtime modal dialog hooks.

Menu Bar Structure (APP_MENU_BAR)

typedef struct {
    APP_MENU_HEADER headers[8];     /* Up to 8 top-level menu headers */
    int             header_count;   /* Number of registered headers */
    int             active_menu;    /* -1 if closed, or active open header index */
    int             hover_menu;     /* Currently hovered header index */
    int             hover_item;     /* Currently hovered dropdown item index */
    char            right_text[64]; /* Right-aligned margin status text */
    APP_MENU_STYLE  style;          /* CLASSIC_3D (beveled) or MODERN_CARD */
} APP_MENU_BAR;

4. Window Subsystem API Reference

init_wnd_mgr ER

Initializes the Sakamura Window Manager and binds the master display framebuffer.

ER init_wnd_mgr(GDEV *screen_dev);
opn_wnd WND*

Instantiates, positions, and maps a new window. Places the window at the top of the z-order stack.

WND* opn_wnd(const char *title, H x, H y, H w, H h, UW attr);
Parameter Type Description
title const char* Window title rendered in the sliding tab or title bar.
x, y H Initial top-left frame position in screen coordinates.
w, h H Total frame width and height in pixels.
attr UW Bitwise combination of WND_ATTR_* flags.
cls_wnd ER

Destroys the specified window, removes it from the z-order list, and invalidates uncovered screen regions.

ER cls_wnd(WND *wnd);
inval_wnd ER

Marks a window client area as dirty, scheduling an immediate call to its paint callback.

ER inval_wnd(WND *wnd);
app_menu_set_about_hook / app_menu_create_about_dialog WND*

Universal runtime hook for application About boxes. Allows mobile targets to route to modal sheets and desktop targets to floating windows with zero #ifdef in application code.

void app_menu_set_about_hook(AppMenuAboutHookFn hook);
WND* app_menu_create_about_dialog(const char *app_title, const char *jp_title, const char *desc, const char *attribution, int x, int y);

5. Canonical Implementation Examples

The following example demonstrates creating a complete native B-System application window with an interactive menu bar: 

#include <btron/wnd.h>
#include <btron/app_menu.h>

typedef struct {
    APP_MENU_BAR menu_bar;
} MyApp;

static void my_app_paint(WND *wnd, GDEV *dev) {
    MyApp *app = (MyApp*)wnd->user_data;
    
    /* 1. Clear client background */
    RECT r = { 0, 0, dev->width, dev->height };
    fill_rec(dev, &r, COLOR_WHITE);

    /* 2. Paint in-window menu bar */
    app_menu_paint_bar(&app->menu_bar, dev);
    app_menu_paint_dropdown(&app->menu_bar, dev);
}

static void my_app_events(WND *wnd, const EVT *evt) {
    MyApp *app = (MyApp*)wnd->user_data;
    int cmd = 0;

    if (evt->type == EV_MOUSE_MOVE) {
        if (app_menu_handle_mouse_move(&app->menu_bar, evt->pos.x, evt->pos.y)) {
            inval_wnd(wnd);
        }
    } else if (evt->type == EV_KEY_DOWN) {
        if (app_menu_handle_key(&app->menu_bar, evt->key, evt->mod, &cmd)) {
            inval_wnd(wnd);
            if (cmd == 100) cls_wnd(wnd); /* Quit */
        }
    }
}
