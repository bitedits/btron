B-Core: InterCore Streaming Protocol

The verified heart of the clean-room BTRON microkernel — a five-call, brokerless, non-blocking pub/sub nexus formalized in Rocq/Coq and executable as an OCaml oracle: pub · sub · spawn · snd · rcv.

Scope: Why the Nexus Is the Kernel

B-Core specifies the InterCore protocol, the message fabric on which every other B-System plane is built: input, UI, I/O, and decode actors exchange data exclusively through publisher and reader cursors, never through locks, blocking mailboxes, or a broker daemon. The protocol is the microkernel in the minimal sense: five calls, static tables, one bounded sector pool, and a small closed set of invariants that no sequence of calls can escape.

The normative sources are doc/txt/ASYNC.txt §0.1 (taxonomy), doc/txt/SMP-AMP-SYNC-IO-HARDENING.txt §7.3–§7.4 (the shipped C contract and its pass criteria, whose ruling R7 supersedes the older blocking-receive text), doc/txt/INTERPRETER.txt §3 (system-nexus model), and doc/txt/IO.txt §5 (the EVT queue). The executable ground truth is the OCaml oracle verify/models/media_intercore_model.ml; the proofs are the Rocq theory verify/models/media_intercore_properties.v. This book documents the operational contract; theorem statements and their proofs are catalogued on the B-Core theorems page and are not re-derived here.

Implementation status. The five calls are a frozen contract destined for src/mp/async_core.h (multiprocessing home, per hardening document decision D3). Until that header lands, the OCaml oracle is the executable specification, and the classical T-Kernel message surface in src/kernel/ipc_msg.c keeps its current behaviour: it is not rerouted onto InterCore until the surface passes the §7.4 metrics on two ports.

Part 1 — Architecture & Conceptual Model

1.1 Star Topology, No Broker

Each publisher owns one bounded ring. Subscribers attach directly to the publisher's history; there is no intermediary queue, router, or daemon between them. One publisher per core is admitted, which makes the star a per-core structure and removes any shared mutable broker state from the data path. 

                    ┌─────────────────────────┐
   producer task    │  publisher cursor  w_id │  w_cap ring sectors
   (snd w data) ───►│  w_hist  w_enq  w_drop  │◄── one publisher per core
                    └────┬────────┬───────┬───┘
                         │        │       │      (direct attach, no broker)
                    ┌────▼───┐ ┌──▼────┐ ┌▼─────┐
                    │ reader │ │ reader│ │reader│  each pins r_start at sub-time
                    │ r_cur  │ │ r_cur │ │r_cur │  each drains with rcv, O(1)
                    └────────┘ └───────┘ └──────┘
                       core 0      core 1     core 3 (AMP I/O)

A subscriber's position is a cursor into the publisher's absolute sequence space (w_hist[seq]), not a slot in a shared consumer ring. Receipt is therefore a pure read: O(1), never a memmove, and never a wait. Transport is zero-copy at the sector granularity: a sent item charges the static sector pool exactly while some live subscriber can still be handed it, and an unread publisher holds zero sectors — there is no broker that stores traffic for an absent consumer.

1.2 The Five-Call Taxonomy

The complete protocol alphabet. Everything an actor may do to another actor's data is one of these five.

CallIntentBlocks?Fails how?
pub [capacity]Create a publisher cursor; return its system-wide writer id.NeverInert refusal: table full.
sub [publisher]Bind a reader cursor to one live publisher, pinned to its current tail.NeverInert refusal: publisher dead, owned by another task, or reader table full.
spawn [core; program; cursors]Create a Task on the named core with exclusive ownership of the listed cursors (SPN).NeverTyped refusal: bad core, bad/taken cursor, shared publisher, no task slot. Every refusal is inert.
snd [writer; data]Non-blocking append into the publisher's ring.NeverBAD_CURSOR or FULL(n) — and FULL carries the running drop count.
rcv [reader]Non-blocking receipt of the next item at the reader's cursor.NeverBAD_CURSOR or EMPTY. There is no fourth, blocking case (ruling R7).

Ruling R7 of the hardening document is explicit: an earlier text allowed rcv on an empty queue to "yield to the scheduler". That is superseded — a scheduler yield on the drain path reintroduces exactly the sleep/wake transition the Zero-Switch Actor Topology exists to eliminate. rcv returns EMPTY to the caller and the actor keeps its timeslice.

1.3 Cursor & Task Lifecycle

Writer cursor

  1. Dead slot — present in the static table, w_live = false.
  2. Live, unowned — after pub(cap) revives the first dead slot; only pre-spawn calls may touch it.
  3. Live, owned — after spawn grants it to exactly one task; only that task may snd, and fan-out via sub needs that owner.

Reader cursor

  1. Dead slot in the static table.
  2. Joined at the tail — sub(w) pins r_start = r_cursor = w_enq: a late joiner can never replay history.
  3. Draining — rcv advances r_cursor one absolute sequence step per receipt, bounded by the publisher watermark.

Task

  1. Admission — spawn validates in fixed order: core id 0 … cores-1; non-empty, live cursor list; no cursor already owned; at most one publisher in the grant; the target core hosts no other publisher; a free task slot exists.
  2. Ownership by value — granted cursors live in t_cursors; ids are dense small integers, so ownership transfers with no handle and no pointer escape.
  3. Exclusion — an owned cursor may be touched only by its owning task. This is the mutex that is not there: no lock object, no wait order, no priority inversion, and nothing to release — ownership ends with the task.

1.4 Concurrency & Safety Model

  • Zero post-boot allocation (NASA JPL Rule 3 compliance): writer, reader and task tables and the 64-sector pool exist before the first call; bus0 is a static value.
  • Refusal is stuttering. Every refusal (pub/sub returning no id, or an error result of snd/rcv/spawn) leaves the bus state unchanged. A rejected call is indistinguishable from a no-op.
  • Retention floor. A publisher's retained span is resident = w_enq − min(w_enq, cursors of live subscribers) and never exceeds w_cap. Absent readers do not force retention: the watermark is a floor, not a debt.
  • Conservation. At every reachable state pool_free + Σ resident = sector_pool. rcv is what returns sectors; a drain to quiescence restores the full pool. The bookkeeping identity enq = deq + drop holds per publisher.
  • Commutation law. Calls on disjoint cursors commute; the relative order of dependent calls (a sub before or after a snd) is an observable difference — the early subscriber reads the item, the late subscriber reads empty. This is the deliberate, specified freedom of a schedule, not a race.
  • Closed class. No word over the five-call alphabet, in any interleaving on any number of cores, escapes the well-formedness class bus_wf (theorems page, group I9).

1.5 Real-Time Planes & the Gate

InterCore carries the ASYNC plane contracts of include/btron/async_rt.h: the input plane at a 1000 µs period with a 500 µs WCET budget, the UI plane at 8333 µs with 4000 µs, and the AMP I/O core (core 3) free-running at 250 µs with a 500 µs budget. Cursor drains are budgeted inside these periods; the pointer path uses the wait-free seqlock snapshot (pointer_slot_t) rather than a lock.

Conformance is reported as five rows — planes, ring, intercore, amp, io_wcet — behind the BTRON_MP compile flag. The gate is honest: a shipped one-core port prints PASS(4/5, 1 SKIP) because amp cannot be observed there; with the flag off only planes passes; --require=amp on a one-core port is a FAIL, never a quiet migration to core 0. SKIP is never reported as PASS.

Part 2 — Data Structures, Types & Enumerations

2.1 Contract Types (C99 surface, §7.3)

Cursor identities are dense small integers indexing static tables — no handles, no pointer escape. The shipped table widths (§7.4 row pub=4 sub=8) fix the address space. 

/* src/mp/async_core.h (contract; oracle in media_intercore_model.ml) */

typedef int reader_id_t;   /* 0 .. max_readers-1 (8)  */
typedef int task_id_t;     /* 0 .. max_tasks-1   (8)  */
typedef int core_id_t;     /* 0 .. bus.cores-1        */

typedef enum {
    SNDR_OK,          /* item appended, pool charged          */
    SNDR_FULL         /* ring or pool exhausted; item dropped */
} snd_status_t;

typedef struct { snd_status_t kind; int drop_count; } snd_result_t;

typedef enum {
    RCVR_DATA,        /* payload written to *out              */

2.2 Records & Field Invariants

Executable oracle records (media_intercore_model.ml §2):

type cursor_ref = CPub of int | CSub of int

type writer = { w_id : int; w_live : bool; w_cap : int;
                w_enq  : int;      (* accepted sends; also next sequence number *)
                w_drop : int;      (* refused because the ring or pool was full *)
                w_hist : int list; }   (* payload at absolute seq, oldest first *)

type reader = { r_id : int; r_live : bool; r_writer : int;
                r_start  : int;    (* watermark pinned by sub: no replay     *)
                r_cursor : int;    (* absolute sequence position             *)
                r_deq    : int;    (* receipts                               *)
                r_log : int list; };  (* everything received, in order       *)

type task = { t_id : int; t_live : bool; t_core : int; t_prog : int;
              t_cursors : cursor_ref list; };   (* ownership, by value       *)

type bus  = { cores : int; writers : writer list; readers : reader list;
              tasks : task list; pool_free : int; };

The Rocq theory derives the two counters that the oracle stores, eliminating a second bookkeeping model that could disagree with itself:

Record writer : Type := mk_writer { w_live : bool; w_cap : nat;
                                    w_hist : list nat; w_drop : nat }.
Record reader : Type := mk_reader { r_live : bool; r_wid : nat;
                                    r_start : nat; r_cur : nat }.
(* in Coq:  w_enq := length w_hist   and   r_deq := r_cur - r_start  *)

2.4 The EVT Bounded Queue (I/O Plane Projection)

The event transport onto the AMP I/O core is a single-producer / single-consumer ring of 256 slots. Index arithmetic is masking, never modulo; head is consumer-owned, tail is producer-owned; and publication is two-phase — store the item invisibly, then advance the tail — so a consumer can never observe a half-written slot. 

type evt = { buf : int list; head : int; tail : int }
let evt_idx i = i land (event_queue_size - 1)       (* masked index              *)
let evt_store   e v = (* write buf[tail-slot] only; invisible to consumer        *)
let evt_publish e   = { e with tail = e.tail + 1 }  (* the single visible step   *)
let evt_put   e v   = if full then refuse else evt_publish (evt_store e v)

A full queue refuses the producer rather than evicting the consumer's unread item: overflow is a counted drop, and the §7.4 acceptance row requires zero EVT overflow on the shipped soak.

Part 3 — API Reference (the Five Calls)

3.1 pub — create a publisher cursor

pubwriter_id_t

Revives the first dead writer slot, marks it live with the requested ring capacity, and returns its dense id. The tables exist before the first call: pub allocates nothing.

writer_id_t pub(size_t capacity); /* C contract §7.3 */ bus * writer_id_t option pub bus capacity; /* oracle: None = inert refusal */

Parameters

Return

Some w_idA dead writer slot exists (< 4 live).Slot revived with w_cap = capacity.

Postconditions

Granted ids are distinct; ids never drift; a revived slot reuses its table position cleanly.

3.2 sub — join a reader at the tail

subreader_id_t

Binds a reader cursor to exactly one live, usable publisher and pins it to the publisher's current watermark. A late joiner sees only what is sent after it joins: history is never replayed.

reader_id_t sub(writer_id_t pub); /* C contract §7.3 */ bus * reader_id_t option sub ?(by) bus wid; /* oracle */

Parameters

NameTypeDirDescription
pub / widwriter_id_t[in]Target publisher. Must be live and, if already spawned to a task, addressed by that task.

Return

Some r_idPublisher live & usable; a dead reader slot exists.r_start = r_cursor = w_enq, r_deq = 0.

Preconditions / Postconditions

Fan-out to a publisher already owned by a task requires that owner to call: an unowned publisher is subable only before any spawn. Each live subscriber becomes part of the publisher's retention floor until it is drained.

3.3 spawn — ownership without a mutex

spawnspawn_result

Creates a Task on the named core and transfers exclusive ownership of the listed cursors by value. The guard order below is normative; every refusal is inert — a rejected spawn never leaves half-granted ownership behind.

3.4 snd — non-blocking send that says why

sndsnd_result

Appends one payload item to the publisher's ring. A full publisher refuses with FULL(drop_count) rather than blocking or wrapping: the drop count is required evidence for the §7.4 acceptance identity, and a bare boolean could not be told apart from a policy drop.

snd_result_t snd(writer_id_t, const void *data); /* C contract §7.3 */ bus * snd_result snd ?(by) bus wid data; /* oracle */

3.5 rcv — strictly non-blocking O(1) receipt

rcvrcv_result

Reads the item at the reader's absolute cursor, advances the cursor, and — because advancing is what releases retention — hands sectors back to the pool. Exactly three results exist; there is no blocking fourth case.

rcv_result_t rcv(reader_id_t, void *out); /* C contract §7.3 */ bus * rcv_result rcv ?(by) bus rid; /* oracle */

Parameters

NameTypeDirDescription
readerreader_id_t[in]Live reader whose publisher is live, and usable by the calling task.
outvoid *[out]Destination for the payload when the result is DATA.

Return

ResultConditionEffect
R_DATA vr_cursor < w_enq.v = w_hist[r_cursor]; cursor and r_deq advance; released sectors return to pool_free.
R_EMPTYr_cursor ≥ w_enq (cursor at the watermark).Inert. The caller keeps running; no scheduler yield (R7).
R_BAD_CURSORReader or its publisher dead; caller not the owner.Inert.

Postconditions

A reader's receipts are always the exact contiguous slice of the publisher's history from r_start to r_cursor — values cross the star intact, in order, exactly once. Catch-up is bounded: draining k times reduces the pending gap by exactly min(k, pending) and never widens it.

Part 4 — Canonical Code Examples

4.1 Producer & consumer actors on the star

The idiomatic lifecycle: publish, fan out subscribers, hand ownership to budgeted tasks, then run the non-blocking send and drain loops.

/* #include <mp/async_core.h> once the contract header lands. */
#include <btron/async_rt.h>

static writer_id_t g_bus_w;

void input_driver_init(void) {
    g_bus_w = pub(INPUT_RING_CAPACITY);          /* refuse-when-full ring      */

    reader_id_t ui  = sub(g_bus_w);              /* pinned to tail, no replay  */
    reader_id_t iod = sub(g_bus_w);

    spawn(CORE_UI, ui_drain_actor,  (cursor_t[]){ CSub(ui)  });
    spawn(CORE_IO, iod_drain_actor, (cursor_t[]){ CSub(iod) });
    spawn(CORE_UI, input_driver_actor, (cursor_t[]){ CPub(g_bus_w) });
    /* any T_BAD_CURSOR / T_CURSOR_TAKEN / T_SHARED_PUBLISHER is inert:
       nothing was half-granted, so a corrected spawn is always safe.         */
}

/* Producer tick: never blocks, never wraps, always says why. */
void input_driver_actor(void) {
    for (;;) {
        period_wait(INPUT_PERIOD_US);
        item_t evt = poll_bus();                 /* drain hardware into items  */
        snd_result_t r = snd(g_bus_w, &evt);
        switch (r.kind) {
        case SNDR_OK:   break;
        case SNDR_FULL: telemetry_note_drop(r.drop_count); break;  /* counted  */
        }
    }
}

/* Consumer budget: drain what exists; EMPTY is progress; no yield. */
void ui_drain_actor(void) {
    for (;;) {
        period_wait(INPUT_PERIOD_US);
        item_t out;
        unsigned drained = 0;
        while (drained < ASYNC_ISR_TRB_BUDGET) { /* bounded catch-up, I16      */
            rcv_result_t r = rcv(g_ui_reader, &out);
            if (r == RCVR_EMPTY) break;          /* at the watermark: done     */
            if (r == RCVR_BAD_CURSOR) break;     /* contract violation: log    */
            handle(&out);
            drained++;
        }
    }
}

4.2 EVT publish — two phases, one writer per field

/* I/O core producer side (IO.txt §5): store, then publish — never swapped. */
evt_store(&e, sample);           /* writes buf[tail & 255]; invisible         */
evt_publish(&e);                 /* tail++ is the single visible step         */

/* UI core consumer side */
if (evt_get(&e, &v) == EVT_DATA) use(v);  /* head++ only; never reads an
                                             unpublished slot                */

Metrics & Acceptance (§7.4)

The ring row the shipped build must print, and the identity that makes the three numbers evidence rather than decoration: 

[ASYNC] ring: enq=1000000 deq=998412 drop=1588
        enq == deq + drop            -- conservation identity (I8)
        pool_free == sector_pool     -- after drain to quiescence (no leak)
  • Every accepted item was either delivered or counted as a drop; a third outcome is impossible.
  • Drain-to-quiescence must restore the whole 64-sector pool — the assertion that catches leaks.
  • Rows that were not compiled in report SKIP, never PASS; a required row missing on the current port is a FAIL.
