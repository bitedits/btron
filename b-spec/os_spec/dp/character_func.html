2.5 Функції виводу тексту та символів (Text & Character Functions)

2.5.1 Налаштування параметрів текстового середовища

gset_chp / gget_chp
Set / Get Text Position
Встановлення та отримання поточної позиції виведення тексту

【Синтаксис / Прототип】

ERR gset_chp(GID gid, PNT *pos)
ERR gget_chp(GID gid, PNT *pos)

【Параметри】

GID  gid    Дескриптор середовища малювання
PNT *pos    Вказівник на структуру координат точки (X, Y)

【Детальний опис】

gset_chp() встанолювє нову поточну позицію пера малювання тексту у середовищі gid. gget_chp() зчитує поточні координати пера.

gset_chc / gget_chc
Set / Get Text Color
Встановлення та отримання кольору тексту (передній план / фон)

【Синтаксис / Прототип】

ERR gset_chc(GID gid, COLOR fg, COLOR bg)
ERR gget_chc(GID gid, COLOR *fg, COLOR *bg)

【Параметри】

GID   gid   Дескриптор середовища малювання
COLOR fg    Колір переднього плану / символу (Foreground Color)
COLOR bg    Колір фону під символом (Background Color)
gset_chd / gget_chd
Set / Get Text Direction and Spacing
Встановлення та отримання напрямку письма й міжсимвольних інтервалів

【Синтаксис / Прототип】

ERR gset_chd(GID gid, W dir, CGAP *gap)
ERR gget_chd(GID gid, W *dir, CGAP *gap)

【Параметри】

GID   gid   Дескриптор середовища малювання
W     dir   Напрямок виведення тексту (TORIGHT, TOLEFT, TOUP, TODOWN)
CGAP *gap   Структура міжсимвольних інтервалів та відступів (CGAP)
gset_fon / gget_fon
Set / Get Font Specifier
Призначення та зчитування специфікації шрифту FSSPEC

【Синтаксис / Прототип】

ERR gset_fon(GID gid, FSSPEC *spec)
ERR gget_fon(GID gid, FSSPEC *spec, FNTINFO *info)

【Параметри】

GID      gid    Дескриптор середовища малювання
FSSPEC  *spec   Специфікація гарнітури, накреслення та розміру шрифту
FNTINFO *info   Буфер для збереження виміряних метрик вибраного шрифту
gset_scr / gget_scr
Set / Get Script Language
Встановлення та отримання кодової площини / мовного скрипту

【Синтаксис / Прототип】

ERR gset_scr(GID gid, W script)
ERR gget_scr(GID gid, W *script)

2.5.2 Метрики та вимірювання тексту

gget_chw / gget_chh
Get Character Width / Height
Отримання ширини та висоти окремого символу

【Синтаксис / Прототип】

W gget_chw(GID gid, TC ch)
W gget_chh(GID gid, TC ch)

【Параметри】

GID gid     Дескриптор середовища малювання
TC  ch      Символьний код TRON Code

【Значення, що повертається】

>= 0    Ширина або висота символу ch у пікселях
< 0     Помилка (EG_GID, EG_PAR)
gget_stw / gget_sth / gget_str
Get String Metrics / Bounding Box
Вимірювання повної довжини, висоти та обмежувального прямокутника рядка

【Синтаксис / Прототип】

W   gget_stw(GID gid, TC *str, W len)
W   gget_sth(GID gid, TC *str, W len)
ERR gget_str(GID gid, TC *str, W len, RECT *r)

【Детальний опис】

Обчислюють ширину, висоту та прямокутник верстки r для рядка символів str завдовжки len символів з урахуванням поточного шрифту й інтервалів.

2.5.3 Функції малювання символів та рядків

gdra_chr / gdra_chp
Draw Character (Auto / Specified Position)
Малювання символу у поточній або вказаній позиції

【Синтаксис / Прототип】

ERR gdra_chr(GID gid, TC ch, W mode)
ERR gdra_chp(GID gid, PNT *pos, TC ch, W mode)

【Параметри】

GID  gid    ID середовища малювання
PNT *pos    Точка виведення (NULL = поточна позиція пера chp)
TC   ch     Символьний код TRON Code
W    mode   Режим накладання (DM_PAINT, DM_OVER тощо)
gdra_str / gdra_stp
Draw String (Auto / Specified Position)
Малювання рядка символів

【Синтаксис / Прототип】

ERR gdra_str(GID gid, TC *str, W len, W mode)
ERR gdra_stp(GID gid, PNT *pos, TC *str, W len, W mode)

【Параметри】

GID  gid    ID середовища малювання
PNT *pos    Початкова точка виведення рядка (NULL = поточна позиція chp)
TC  *str    Символьний рядок у кодуванні TRON Code
W    len    Кількість символів у рядку
W    mode   Режим малювання
gcop_chr
Get Glyph Mask Bitmap
Отримання растрової бітової маски гліфа у буфер

【Синтаксис / Прототип】

ERR gcop_chr(GID gid, TC ch, BITMAP *bmap, PNT *offset)

【Параметри】

GID     gid     Дескриптор середовища малювання
TC      ch      Код символу TRON Code
BITMAP *bmap    Вказівник на бітову карту для збереження растру гліфа
PNT    *offset  Буфер для збереження базового зсуву гліфа відносно лінії шрифту
