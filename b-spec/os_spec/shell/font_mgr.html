3.9 Менеджер шрифтів (Font Manager)

3.9.1 Функції Менеджера шрифтів

3.9.1.1 Загальні відомості

Менеджер шрифтів (Font Manager) керує реєстрацією, вибором, масштабуванням, трансформацією (нахил, товщина, поворот) та генерацією растрових бітових карт символів для всіх системних і прикладних програм у середовищі BTRON3. Підтримуються растрові шрифти (фіксованого та змінного розміру), векторні контурні шрифти та контури TrueType.

3.9.1.2 Поняття шрифту, сімейства та набору шрифтів (Font Set)

Шрифтові дані (Font Data / FDEF)
Окремий файл або блок пам'яті, що містить гліфи та метрики для певного набору символів і розміру.
Сімейство шрифтів (Font Family)
Сукупність шрифтових даних однакового стилю (наприклад, Mincho, Gothic).
Набір шрифтів (Font Set / Font Descriptor)
Динамічно створений екземпляр шрифту із заданим розміром, стилем, кутом повороту та атрибутами. Ідентифікується цілим дескриптором шрифту (fdesc).

3.9.1.3 Типи розміщення шрифтових даних

  • Фіксовані шрифти (FT_MEM) : постійно розміщені в ROM або системній пам'яті.
  • Динамічні шрифти (FT_FILE) : завантажуються з файлів реальних об'єктів за потреби.

3.9.2 Структури даних та константи

□ Заголовок визначення шрифту (FDEF)

typedef struct {
    H           fclass;         /* Клас шрифту (FTC_MINCHO, FTC_DEFAULT тощо) */
    H           attr;           /* Атрибути (нахил, напівжирний тощо) */
    TC          name[12];       /* Назва сімейства */
    UB          size;           /* Висота базового растру */
    UB          width;          /* Максимальна ширина символу */
    UB          base;           /* Базова лінія (baseline) */
    UB          leading;        /* Міжрядковий інтервал (leading) */
    TC          fullname[20];   /* Повна назва */
    TC          topcode;        /* Перший код символу */
    TC          lastcode;       /* Останній код символу */
    UB          imgform;        /* Формат растру: 0=фікс. растр, 1=варіативний, 2=вектор, 3=TrueType */
    UB          widform;        /* Формат ширини: 0=простий, 1=індексний, 2=з шириною образу */
    W           datasize;       /* Розмір даних у байтах */
    OFFSET      offimage;       /* Зсув до растрових образів */
    OFFSET      offwidth;       /* Зсув до таблиці ширини */
    OFFSET      offnote;        /* Зсув до анотації */
} FDEF;

□ Специфікація набору шрифтів (FSSPEC)

typedef struct {
    TC          name[12];       /* Назва сімейства (NULL = за замовчуванням) */
    FCLASS      fclass;         /* Клас шрифту */
    FATTR       attr;           /* Атрибути стилю */
    SIZE        size;           /* Розмір символу (ширина, висота) */
    H           angle;          /* Кут повороту (0..359 градусів) */
} FSSPEC;

□ Інформація про зображення символу (FDATA / FCDATA)

typedef struct {
    RECT    frame;      /* Межі символу */
    H       width;      /* Ширина символу */
    H       height;     /* Висота символу */
    PNT     imgofs;     /* Зсув зображення */
    UH      family;     /* Сімейство */
    UH      fid;        /* ID шрифту */
} FCDATA;

typedef struct {
    UW      attr;       /* Атрибути */
    UH      height;     /* Максимальна висота */
    UH      width;      /* Максимальна ширина */
    UH      base;       /* Базова лінія */
    UH      leading;    /* Інтервал */
    SIZE    asize;      /* Розмір символу */
    UH      aangle;     /* Кут повороту */
    UH      pixbits;    /* Глибина кольору бітової карти (1, 2, 4, 8) */
    UB      *image;     /* Адреса растрової карти символу */
    FCDATA  ch[1];      /* Дані для кожного запитаного символу */
} FDATA;

3.9.3 Системні виклики Менеджера шрифтів

fdef_fnt
Define Font
Реєстрація шрифтових даних у системі

【Синтаксис / Прототип】

WERR    fdef_fnt(FLOC loc, W spec)

【Параметри】

FLOC    loc     Розміщення шрифту (вказівник на пам'ять або посилання на файл)
W       spec    Тип розміщення (FT_MEM | FT_FILE | FT_RES | FT_SYSTEM)

【Значення, що повертається】

>= 0    ID зареєстрованого шрифту (fid)
 < 0    Помилка (Код помилки)

【Детальний опис】

Реєструє нові шрифтові дані в системному пулі шрифтів і повертає унікальний fid.

【Коди помилок】

EX_NOSPC: Нестача пам'яті.
EX_PAR  : Неприпустимий формат даних або spec.

ERR fdel_fnt(W fid)

【Значення, що повертається】

【Детальний опис】

Видаляє зареєстрований шрифт із системної таблиці.

【Коди помилок】

EX_FTID : Шрифт fid не існує.

Get Glyph Image
Отримання растрового зображення та метрик символу

【Синтаксис / Прототип】

WERR    fget_img(W fdesc, FDATA *cimg, W size, W script, TC ch, UW mode)

【Параметри】

W       fdesc   Дескриптор набору шрифтів

W       size    Розмір буфера cimg у байтах
W       script  Скрипт символу
TC      ch      Код символу TRON Code
UW      mode    Режим: FT_IMAGE (отримати растр), FT_SYS (у системну пам'ять)

【Значення, що повертається】

>= 0    Кількість оброблених символів (1)
 < 0    Помилка (Код помилки)

【Детальний опис】

【Коди помилок】

EX_ADR  : Недопустима адреса cimg.
EX_FTD  : Дескриптор fdesc не існує.
EX_NOSPC: Недостатній розмір буфера size.
