3.3 Менеджер елементів управління (Parts Manager)

3.3.1 Огляд підсистеми

Менеджер елементів управління (Parts Manager) забезпечує стандартні графічні елементи UI (widgets) для панелей та вікон: текстові поля, числові поля, перемикачі, список-селектори, смуги прокручування, повзунки.

Кожен елемент (Part) реєструється у вікні або панелі та отримує унікальний PAID (Parts ID). Стан, поточне значення та відображення керуються функціями менеджера.

Елемент має такі властивості: стан відображення (P_DISP), стан введення (активний/неактивний), поточне значення, виділена область (для box-елементів), параметри відображення.

3.3.2 Типи елементів управління

3.3.2.1 Текстовий блок (Text Box / TB_PARTS)

Однорядкове поле введення тексту. Підтримує: редагування (replace-editor), виділення підрядка, D&D (переміщення/копіювання), буфер обміну (Tray), IME-перетворення (кана→канджі). Автопрокрутка при переповненні ширини.

P_DISP0 = прихований / 1 = відображений
P_INACT0 = активний (курсор/виділення) / 1 = неактивний
P_DISABLE0 = дозволений (рамка) / 1 = заборонений (підкреслення)
P_NOFRAME0 = з рамкою / 1 = без рамки
P_EMPHAS0 = нормальна рамка / 1 = виділена рамка
P_APPEND0 = заміна (виділяється весь текст) / 1 = дозапис (курсор в кінці)
P_PARTDISP0 = атрибути за замовч. / 1 = задані атрибути

3.3.2.2 Секретний текстовий блок (Secret Text Box / XB_PARTS)

Ідентичний TB_PARTS, але символи не відображаються (поле пароля). Завжди виділений весь текст; D&D недоступний; IME-перетворення недоступне.

3.3.2.3 Числовий блок (Number Box / NB_PARTS)

Поле введення числових значень (цілих або дійсних). Формат задається fmt. Підтримує обмеження діапазону (min/max), символ заборони (S_UNDEF/L_UNDEF/D_UNDEF).

3.3.2.4 Серійний блок (Serial Box / SB_PARTS)

Поле редагування з кількома полями (рядки і числа). Навігація між полями клавішею Tab.

3.3.2.5 Текстовий Alternate Switch (AS_PARTS)

Перемикач ON/OFF з текстовою назвою та індикатором. Клік змінює стан ON↔OFF.

3.3.2.6 Текстовий Momentary Switch (MS_PARTS)

Кнопка натискання з текстовою назвою. Спрацьовує при відпусканні вказівника у межах. Підтримує P_DCLICK (подвійний клік) та P_PRESS (реакція на утримання).

3.3.2.7 Піктограмний Alternate Switch (PA_PARTS)

Аналог AS_PARTS, але відображає дві бітові карти (ON/OFF стани). onpat / offpat — номери BMAP_DATA; offpat=0 → інверсія onpat.

3.3.2.8 Піктограмний Momentary Switch (PM_PARTS)

Аналог MS_PARTS з бітовою картою замість тексту.

3.3.2.9 Switch Selector (WS_PARTS)

Група перемикачів: один вибраний зі списку варіантів. Поточне значення — номер вибраного (1..N; 0 = нічого).

3.3.2.10 Scroll Selector (SS_PARTS)

Список з прокручуванням: варіанти + вертикальна смуга прокручування. Клавіатурна навігація — через пряме встановлення значення.

3.3.2.11 Повзунок (Volume / VL_PARTS)

Аналог горизонтальної/вертикальної смуги прокручування з ручкою (knob). Підтримує Smooth/Area/Jump переміщення. Перервана операція повертає P_BREAK.

3.3.3 Структури та константи

□ ID елемента

typedef W   PAID;   /* Parts ID */

□ Типи елементів

#define TB_PARTS    1   /* Текстовий блок */
#define XB_PARTS    2   /* Секретний текстовий блок */
#define NB_PARTS    3   /* Числовий блок */
#define SB_PARTS    4   /* Серійний блок */
#define AS_PARTS    5   /* Текстовий Alternate Switch */
#define MS_PARTS    6   /* Текстовий Momentary Switch */
#define PA_PARTS    7   /* Піктограмний Alternate Switch */
#define PM_PARTS    8   /* Піктограмний Momentary Switch */
#define WS_PARTS    9   /* Switch Selector */
#define SS_PARTS    10  /* Scroll Selector */
#define VL_PARTS    11  /* Повзунок (Volume) */

□ Бітові прапори типу/атрибутів елемента (поле type/ty)

#define P_TYPE      0x001f  /* Маска типу */

#define P_HALIGN    0x0020  /* Вертикальне/горизонтальне розташування */
#define P_PRESS     0x0040  /* Реакція на утримання (MS/PM) */
#define P_NUMBER    0x0040  /* Нумерація варіантів (WS) */
#define P_DOUBLE    0x0040  /* Дворядна сітка (WS) */
#define P_SBAR      0x0040  /* Зі смугою прокручування (VL) */
#define P_DCLICK    0x0080  /* Виявлення подвійного кліку (MS/PM) */
#define P_NOSEL     0x0080  /* Дозволено вибір 0 (WS/SS) */
#define P_APPEND    0x0080  /* Режим дозапису (TB/XB) */
#define P_NONOB     0x0080  /* Без ручки (VL) */

#define P_EMPHAS    0x0200  /* Виділена рамка */
#define P_NOFRAME   0x0400  /* Без рамки */
#define P_DISABLE   0x0800  /* Заблокований */
#define P_INACT     0x1000  /* Неактивний стан */
#define P_BLINK     0x2000  /* Мерехтіння */
#define P_DISP      0x4000  /* Відображений */
#define P_PARTDISP  0x8000  /* Задані атрибути відображення */

□ Атрибутні коди (meta-коди у списках пунктів)

#define MC_STR      0x1000  /* Рядок */
#define MC_FIG      0x1001  /* Графічні дані */
#define MC_ATTR     0x1002  /* Задати атрибути символів */
#define MC_EMPHAS   0x1400  /* Виділений пункт */
#define MC_INACT    0x1800  /* Недоступний пункт */
#define MC_SFLD     0x0800  /* Рядкове поле (SB) */
#define MC_NFLD     0x0c00  /* Числове поле (SB) */
#define MC_NZERO    0x0200  /* Провідні нулі (NB) */
#define MC_NLEFT    0x0100  /* Вирівнювання вліво (NB) */

□ Числові формати (NB_PARTS)

#define P_LNUM      0x0000  /* Ціле число (32-біт) */
#define P_DNUM      0x0080  /* Дійсне число (64-біт) */
#define P_FIX0      0x0000  /* Фіксована кома, 0 знаків */
#define P_FIX1      0x0010  /* Фіксована кома, 1 знак */
#define S_UNDEF     0x8000      /* Невизначене (16-біт) */
#define L_UNDEF     0x80000000  /* Невизначене (32-біт) */
#define D_UNDEF     1.797693e308 /* Невизначене (64-біт, NaN) */

□ Коди завершення (функції cact_par / cexe_par)

/* Формат поверненого значення: 01PC SSSS SSSS SSSS */
#define P_CHANGE    0x1000  /* Поточне значення змінилось */
#define P_BREAK     0x2000  /* Операція перервана */
#define P_SMASK     0x0fff  /* Маска коду стану */
#define P_MENU      0x6010  /* Перервано через меню */
#define P_EVENT     0x6020  /* Перервано через іншу подію */

/* Коди завершення введення ящику */
#define P_SGL       1   /* Одиночний клік */
#define P_DBL       2   /* Подвійний клік */
#define P_TAB       0   /* Завершення клавішею Tab */
#define P_NL        1   /* Завершення Enter/Newline */
#define P_END       2   /* Завершення клавішею End */
#define P_BUT       3   /* Натискання поза блоком */
#define P_MOVE      4   /* Переміщення поза блок */
#define P_COPY      5   /* Копіювання поза блок */

/* Напрямки (VL/SS) */
#define P_UP        0   /* Вгору */
#define P_DOWN      1   /* Вниз */
#define P_LEFT      2   /* Вліво */
#define P_RIGHT     3   /* Вправо */

/* Режими переміщення (VL/SS) */
#define P_SMOOTH    0   /* Плавне */
#define P_AREA      4   /* Посторінкове */
#define P_JUMP      8   /* Стрибок до позиції */

□ Команди зміни стану (cchg_par)

#define P_ERASE     0x0000  /* Стерти */
#define P_NODISP    0x1000  /* Перейти у стан «прихованого» */
#define P_RDISP     0x8000  /* Перемалювати */

#define P_NORMAL    0x0002  /* Нормальна рамка */
#define P_FRAME     0x0004  /* Увімкнути рамку */
#define P_ENABLE    0x0008  /* Розблокувати */
#define P_ACT       0x0010  /* Зробити активним */

□ Структура атрибутів відображення (PARTDISP)

typedef struct {
    UW      frpat;  /* Патерн рамки/підкреслення (лише P_NOFRAME=0) */
    UW      bgpat;  /* Патерн фону прямокутної зони */
    COLOR   chcol;  /* Колір тексту */
    UW      misc;   /* (не використовується) */
} PARTDISP;

□ Зведена структура визначення елемента (PARTS)

typedef union {
    TEXTBOX  tb;    /* TB_PARTS */
    SECRBOX  xb;    /* XB_PARTS */
    NUMBOX   nb;    /* NB_PARTS */
    SERBOX   sb;    /* SB_PARTS */
    SWSEL    as;    /* AS_PARTS, MS_PARTS */
    PICTSW   pw;    /* PA_PARTS, PM_PARTS */
    SWSEL    ws;    /* WS_PARTS */
    SCRSEL   ss;    /* SS_PARTS */
    VOLUME   vl;    /* VL_PARTS */
} PARTS;

3.3.4 Системні виклики Менеджера елементів управління

При помилці повертається від'ємний код; при успіху — «0» або «+».

ccre_par
Create Part
Реєстрація елемента управління

【Синтаксис / Прототип】

PAID    ccre_par(W wid, PARTS *parts)

【Параметри】

W       wid     ID вікна або панелі
PARTS  *parts   Дані визначення елемента

【Значення, що повертається】

>= 0    ID елемента (PAID > 0)
 < 0    Помилка (Код помилки)

【Детальний опис】

Реєструє елемент, визначений через parts, у вікні/панелі wid. Повертає PAID. При стані P_DISP=1 — одразу відображається. При P_DISP=0 — реєстрація без відображення.

【Коди помилок】

EX_ADR  : Недопустима адреса parts або вказівників у ній.
EX_NOSPC: Нестача пам'яті.
EX_PAR  : Неприпустимі параметри.
EX_WID  : Вікно (wid) не існує.
EX_DNUM : Дані (onpat, offpat, patnum) не зареєстровані.

Create Text Box
Реєстрація текстового блока

【Синтаксис / Прототип】

PAID    ccre_tbx(W wid, UW ty, RECT *r, W txsize, TC *text, PARTDISP *atr)

【Параметри】

PARTDISP *atr    Атрибути відображення (NULL = за замовч.)

【Значення, що повертається】

>= 0    PAID
 < 0    Помилка

【Детальний опис】

Зручна обгортка для створення TB_PARTS без заповнення структури TEXTBOX.
