3.1 Менеджер вікон (Window Manager)

3.1.1 Огляд підсистеми Менеджера вікон

3.1.1.1 Загальні відомості

Менеджер вікон ядра BTRON3 керує багатовіконним середовищем робочого столу: перекриттям вікон у Z-стеку, переміщенням, зміною розмірів, обробкою фокусу введення та графічними елементами рамки (заголовок Titlebar, кнопки управління, смуги прокручування Scrollbars).

Кожне вікно ідентифікується унікальним системним дескриптором WID та прив'язується до власника-процесу.

3.1.1.2 Типи вікон

Менеджер вікон підтримує такі типи вікон:

Головне вікно (Вікно)
Стандартне вікно прикладної програми.
Залежне вікно (Вікно)
Підпорядковане головному; може бути відкрите лише активним процесом.
Вікно переднього плану (Вікно)
Завжди поверх інших; може відкривати лише Frontend-процес.
Внутрішнє вікно (Вікно)
Пов'язує ID середовища малювання з WID без управління рамкою; лише кілька операцій доступні.
Панельне вікно (Вікно)
Захоплює фокус введення для показу діалогів і панелей; не підтримує переміщення/зміну розміру.

3.1.1.3 Атрибути вікна (WDATTR)

При відкритті вікна wopn_wnd() задаються атрибути: 

typedef UW WDATTR;      /* Бітова маска атрибутів вікна */
WA_STD 0 = не нормалізований режим 
1 = нормалізований режим (опційно)
WA_WORK 0 = r задає зовнішній прямокутник 
1 = r задає робочу зону
WA_FRAME 0 =   
1 = r задає зовнішній прямокутник вікна з рамкою
WA_MAIN 0 = головне вікно 
1 = залежне вікно
WA_SIZE 0 = зміна розміру перетягуванням неможлива 
1 = зміна розміру перетягуванням можлива
WA_HHDL 0 = горизонтальна зміна розміру недоступна (лише якщо WA_SIZE = 1)
1 = горизонтальна зміна розміру доступна
WA_VHDL 0 = вертикальна зміна розміру недоступна
1 = вертикальна зміна розміру доступна
WA_RBAR 0 = без правої смуги прокручування
1 = є права смуга прокручування
WA_BBAR 0 = без нижньої смуги прокручування
1 = є нижня смуга прокручування
WA_LBAR 0 = без лівої смуги прокручування
1 = є ліва смуга прокручування
WA_TITL 0 = є рядок заголовка 
1 = немає рядка заголовка
WA_BGDSP 0 = не оновлювати відображення у неактивному стані  
1 = оновлювати відображення навіть у неактивному стані
※
WA_SIZE, WA_TITL визначають форму вікна.
※
Якщо WA_HHDL і WA_VHDL обидва = 1 — довільна зміна розміру. Якщо обидва = 0 — ручки відсутні.
※
Запит перемальовування при закритті панелі надсилається лише вікнам з атрибутом WA_BGDSP.
Атрибути відображення вікна (WDDISP)

Атрибути відображення задаються при відкритті і не можуть змінюватись після. Не застосовуються до внутрішніх та панельних вікон. 

typedef struct {
    UW      frame;      /* Ширина рамки / номер патерну */
    UW      tlbg;       /* Номер патерну фону заголовка */
    UW      barpat;     /* Номер патерну частини смуги прокручування */
    UW      barbg;      /* Номер патерну білої частини смуги прокручування */
    COLOR   tlcol;      /* Колір тексту заголовка (від'ємне = за замовчуванням) */
} WDDISP;

tlbg, barpat, barbg задаються номером даних типу PAT_DATA; 0 = за замовчуванням. tlcol < 0 = колір за замовчуванням. Значення за замовчуванням змінюються менеджером і впливають на всі подальші вікна з атрибутами за замовчуванням.

3.1.1.4 Форма вказівника (курсора)

Форма вказівника автоматично змінюється Менеджером вікон залежно від положення (зона ручки, смуга прокручування, піктограма, робоча зона тощо). Прикладна програма не повинна змінювати форму вказівника поза робочою зоною активного вікна; у робочій зоні — зобов'язана встановлювати форму самостійно.

3.1.1.5 Операції з вікнами

Вікна підтримують такі операції (реалізація Менеджером вікон + прикладна програма): відкриття, закриття, переміщення, зміна розміру, згортання, активація (передача фокуса), прокручування вмісту, перемальовування, D&D між вікнами.

3.1.1.6 Вікнові події (WEVENT / EV_*)

Менеджер вікон формує події для прикладних програм через wget_evt(). Основні типи подій:

EV_KEYDWN / EV_KEYUP
Натискання/відпускання клавіші.
EV_PNTDWN / EV_PNTUP / EV_PNTMOV
Натискання/відпускання/переміщення вказівника.
EV_SWITCH
Переключення активного вікна. Код команди (W_*):
W_MOVE
Переміщення вікна
W_RESIZE
Зміна розміру
W_BSCROLL
Прокручування (кнопка)
W_JSCROLL
Прокручування (стрибок)
W_SWITCH
Переключення активного вікна
W_CLOSED
Вікно закрито
EV_REDISP
Запит перемальовування. src=0: звичайний; src=1: від панелі.
EV_REQUEST
Запит від іншого процесу/менеджера:
W_PASTE
Запит вставки даних (D&D); відповідь W_ACK/W_NAK обов'язкова.
W_DELETE
Запит закриття вікна; відповідь обов'язкова.
W_FINISH
Запит завершення процесу; відповідь обов'язкова.
W_VOBJREQ
Запит від Менеджера об'єктів (відповідь не потрібна).
W_OPENED
Сповіщення батьківського процесу про нове вікно.
EV_MENU
Натискання кнопки меню або PD з клавішею «Команда».
EV_RSWITCH
Переключення активного вікна з необхідністю перемальовування.
EV_INACT
Вікно перейшло з активного у неактивний стан. src=0: переключення; src=1: відкриття панелі.
EV_MSG
Отримано міжпроцесне повідомлення (читається rcv_msg()).
EV_NOMSG
Немає подій/повідомлень (лише для неактивного процесу).

Внутрішні повідомлення MS_MNG1 та MS_MNG2 зарезервовані Менеджером вікон — прикладним програмам їх використовувати заборонено.

3.1.1.7 Функція переднього плану (Frontend)

Спеціальний Frontend-процес може перехоплювати події вікна для попередньої обробки (наприклад, «Екранна клавіатура»). Реєстрація через wdef_fep().

3.1.2 Системні виклики Менеджера вікон

Усі функції повертають від'ємний код при помилці, «0» або «+» при успіху.

wopn_wnd
Open Window
Відкриття вікна (головного або переднього плану)

【Синтаксис / Прототип】

WID wopn_wnd(RECT *r, W org, TC *title, PAT *bgpat, WDATTR attr, WDDISP *atr)

【Параметри】

RECT*r Початковий прямокутник вікна у абсолютних координатах.
Worg ID батьківського/головного вікна (залежне вікно) або 0.
TC*title Рядок заголовка вікна (TRON Code).
PAT*bgpat Фоновий патерн робочої зони (NULL = за замовчуванням).
WDATTRattr Атрибути вікна (комбінація WA_*).
WDDISP*atr Атрибути відображення (NULL = за замовчуванням).

【Значення, що повертається】

>= 0    ID вікна (WID)
 < 0    Помилка (Код помилки)

【Детальний опис】

Створює нове головне або залежне вікно з вказаними атрибутами. Нове вікно автоматично стає активним (отримує фокус введення) і виводиться на передній план. Попередньо активне вікно отримує подію EV_INACT.

Залежне вікно може відкрити лише активний процес (інакше — EX_WPRC). Вікно переднього плану може відкрити лише Frontend-процес. При відкритому вікні панелі з того ж процесу — помилка EX_WND.

【Коди помилок】

EX_ADR  : Недопустима адреса r, org, title, bgpat або atr.
EX_NOSPC: Нестача системної пам'яті.
EX_WID  : Вікно (wid) не існує (батьківське/головне вікно не існує або належить
          іншому процесу).
EX_WPRC : Не є процесом-менеджером вікна (активний процес для залежного вікна;
          Frontend-процес для переднього плану; інші умови).
EX_WND  : Тип/стан вікна не допускає операцію (є відкрита панель цього процесу;
          відкритий повноекранний режим).
wopn_iwd
Open Internal Window
Відкриття внутрішнього вікна

【Синтаксис / Прототип】

WID wopn_iwd(W gid)

【Параметри】

W   gid     ID середовища малювання

【Значення, що повертається】

>= 0    ID вікна (WID)
 < 0    Помилка (Код помилки)

【Детальний опис】

Відкриває середовище малювання gid як внутрішнє вікно. Рамка, управління фокусом і переміщення не виконуються. Для внутрішнього вікна доступні лише: wcls_wnd(), wget_gid(), wset_dat(), wget_dat(). Не є ціллю пошуку в wget_evt() і wfnd_wnd().

【Коди помилок】

EX_NOSPC: Нестача пам'яті.
EG_GID  : ID середовища малювання (gid) не існує.
EX_WPRC : Frontend-процес.
wopn_pwd
Open Panel Window
Відкриття панельного вікна

【Синтаксис / Прототип】

WID wopn_pwd(RECT *r)

【Параметри】

RECT   *r   Абсолютні координати зовнішнього прямокутника

【Значення, що повертається】

>= 0    ID вікна (WID)
 < 0    Помилка (Код помилки)

【Детальний опис】

Відкриває панельне вікно у вказаних координатах. Рамка не малюється; лише управління існуванням. Переміщення/зміна розміру неможливі. При відкритті захоплює фокус введення; попереднє активне вікно отримує EV_INACT. При закритті фокус повертається до попереднього вікна і надсилається EV_SWITCH.

【Коди помилок】

EX_ADR  : Недопустима адреса r або bgpat.
EX_NOSPC: Нестача пам'яті.
EX_WPRC : Frontend-процес.
wcls_wnd
Close Window
Закриття / видалення вікна

【Синтаксис / Прототип】

ERR wcls_wnd(W wid, W opt)

【Параметри】

W   wid     ID вікна
W   opt     0 = звичайне закриття
           != 0 = примусове закриття (без відновлення попереднього стану)

【Значення, що повертається】

= 0     Успішне виконання
< 0     Помилка (Код помилки)

【Детальний опис】

Закриває вікно wid. При закритті активного вікна активується попереднє. Залежні вікна закриваються автоматично. Після закриття WID більше недійсний.

【Коди помилок】

EX_WID  : Вікно (wid) не існує.
EX_WND  : Тип/стан вікна не допускає операцію.
EX_WPRC : Не є процесом-менеджером вікна.
wget_evt
Get Window Event
Отримання вікнової події

【Синтаксис / Прототип】

W   wget_evt(WEVENT *evt, W opt)

【Параметри】

WEVENT *evt     Буфер для події
W       opt     Режим очікування: 0 = чекати; != 0 = не чекати (повернути EV_NOMSG)

【Значення, що повертається】

>= 0    Тип отриманої події (EV_*)
 < 0    Помилка (Код помилки)

【Детальний опис】

Основна функція отримання вікнових подій. Для активного процесу: зчитує апаратні події, шукає відповідне вікно, конвертує координати, перевіряє меню, оновлює форму вказівника, переключає фокус, виконує Frontend-обробку. Для неактивного процесу: зчитує повідомлення; при opt != 0 і відсутності подій повертає EV_NOMSG.

【Коди помилок】

EX_ADR  : Недопустима адреса evt.
wpas_evt
Pass Event to Window Manager
Передача події до Менеджера вікон (для Frontend)

【Синтаксис / Прототип】

W   wpas_evt(W opt)

【Параметри】

W   opt     0 = чекати на завершення обробки; != 0 = не чекати

【Значення, що повертається】

>= 0    Тип події, переданої далі
 < 0    Помилка (Код помилки)

【Детальний опис】

Frontend-процес передає поточну подію (отриману через wget_evt()) далі до цільового вікна без обробки. Використовується для «прозорого» пропуску подій.

【Коди помилок】

EX_WPRC : Не є Frontend-процесом.
EX_WND  : Немає поточної події для передачі.
wugt_evt
Unget Event
Повернення події у чергу (унгет)

【Синтаксис / Прототип】

ERR wugt_evt(WEVENT *evt)

【Параметри】

WEVENT *evt     Подія для повернення у чергу

【Значення, що повертається】

= 0     Успішне виконання
< 0     Помилка (Код помилки)

【Детальний опис】

Повертає подію evt до черги, щоб вона була отримана при наступному виклику wget_evt(). Дозволяє «відкласти» необроблену подію.

【Коди помилок】

EX_ADR  : Недопустима адреса evt.
wsnd_evt
Send Event to Window
Надсилання події до вікна

【Синтаксис / Прототип】

ERR wsnd_evt(W wid, WEVENT *evt)

【Параметри】

W       wid     ID вікна-отримувача
WEVENT *evt     Подія для надсилання

【Значення, що повертається】

= 0     Успішне виконання
< 0     Помилка (Код помилки)

【Детальний опис】

Надсилає подію evt до вікна wid. Використовується для міжпроцесної комунікації через події вікна (наприклад, EV_REQUEST).

【Коди помилок】

EX_ADR  : Недопустима адреса evt.
EX_WID  : Вікно (wid) не існує.
wreq_dsp
Request Redisplay
Запит перемальовування вікна

【Синтаксис / Прототип】

ERR wreq_dsp(W wid)

【Параметри】

W   wid     ID вікна

【Значення, що повертається】

= 0     Успішне виконання
< 0     Помилка (Код помилки)

【Детальний опис】

Видає запит на перемальовування вікна wid. Процес-менеджер вікна отримає подію EV_REDISP при наступному виклику wget_evt().

【Коди помилок】

EX_WID  : Вікно (wid) не існує.
EX_WND  : Тип/стан вікна не допускає операцію.
wrsp_evt
Respond to Event Request
Відповідь на запит події

【Синтаксис / Прототип】

ERR wrsp_evt(WEVENT *evt, W sts)

【Параметри】

WEVENT *evt     Подія-запит (EV_REQUEST), на яку надсилається відповідь
W       sts     W_ACK = успіх; W_NAK = відмова

【Значення, що повертається】

= 0     Успішне виконання
< 0     Помилка (Код помилки)

【Детальний опис】

Надсилає відповідь W_ACK або W_NAK на запит EV_REQUEST (W_PASTE, W_DELETE, W_FINISH). Відповідь є обов'язковою.

【Коди помилок】

EX_ADR  : Недопустима адреса evt.
EX_PAR  : Неприпустиме значення evt або sts.
wwai_rsp
Wait for Response
Очікування відповіді на запит події

【Синтаксис / Прототип】

W   wwai_rsp(WEVENT *evt, W wid, W type)

【Параметри】

WEVENT *evt     Буфер для отриманої відповіді
W       wid     ID вікна-отримувача запиту (0 = будь-яке)
W       type    Тип запиту (W_PASTE, W_DELETE, W_FINISH тощо)

【Значення, що повертається】

>= 0    Статус відповіді (W_ACK або W_NAK)
 < 0    Помилка (Код помилки)

【Детальний опис】

Надсилає запит type до вікна wid та блокується в очікуванні відповіді W_ACK/W_NAK. Під час очікування може отримувати та обробляти інші події.

【Коди помилок】

EX_ADR  : Недопустима адреса evt.
EX_WID  : Вікно (wid) не існує.
EX_PAR  : Неприпустиме значення type.
wsta_dsp
Start Redisplay
Початок перемальовування вікна

【Синтаксис / Прототип】

W   wsta_dsp(W wid, RECT *r, W opt)

【Параметри】

W       wid     ID вікна
RECT   *r       Буфер для прямокутника, що потребує перемальовування
W       opt     0 = звичайне; != 0 = примусове (навіть якщо перемальовування не потрібне)

【Значення, що повертається】

= 0     Перемальовування не потрібне
= 1     Потрібне перемальовування (r містить область)
