3.5 Сегменти текстових вкладок (Text Fusen Segments)

3.5.1 Загальний огляд

Сегменти текстових вкладок (Text Fusen Segments) використовуються у форматі TAD для керування форматуванням, атрибутами символів, версткою сторінок та стилями тексту. Усі сегменти текстових вкладок поділяються на системні (ідентифікатори підтипів 0–127) та розширення додатків (ідентифікатори 128–255).

Сегмент текстової вкладкиID
Сегмент сторінки тексту (Text Page Fusen)TS_TPAGE(0xA0)
Сегмент лінійки тексту / абзацу (Text Ruler Fusen)TS_TRULER(0xA1)
Сегмент шрифту тексту (Text Font Fusen)TS_TFONT(0xA2)
Сегмент атрибутів символів (Text Character Fusen)TS_TCHAR(0xA3)
Сегмент атрибутів тексту (Text Attribute Fusen)TS_TATTR(0xA4)
Сегмент стилю тексту (Text Style Fusen)TS_TSTYLE(0xA5)
(Зарезервовано)------(0xA6〜0xAC)
Змінна тексту (Text Variable Fusen)TS_TVAR(0xAD)
Замітка тексту (Text Memo Fusen)TS_TMEMO(0xAE)
Сегмент текстової вкладки додатка (Application Text Fusen)TS_TAPPL(0xAF)

Сегмент текстової вкладки визначає свій підтип у полі SUBID. Додаток, який зустрічає незнайомий сегмент вкладки, може безпечно пропустити його без порушення обробки решти текстового документа.

Мал. 13 : Структура текстової вкладки

Вкладки форматування застосовуються послідовно в порядку їх появи у тексті. Вони впливають на наступні текстові символи до появи нової вкладки того самого типу.

3.5.2 Сегменти налаштування сторінки тексту (TS_TPAGE)

Сегмент TS_TPAGE визначає параметри сторінки, такі як розмір паперу, орієнтація, поля сторінки, багатоколонкова верстка та колонтитули.

Сегмент формату сторінки (Page Format Fusen / SUBID 0):

Визначає фізичний розмір сторінки, орієнтацію паперу та поля. 

LEN  :  14
SUBID:  0
ATTR :  UB      attr            -- Орієнтація та напрямок верстки (attr)
DATA :  UH      length          -- Довжина (висота) сторінки
        UH      width           -- Ширина сторінки
        UH      top             -- Верхнє поле
        UH      bottom          -- Нижнє поле
        UH      left            -- Ліве поле
        UH      right           -- Праве поле
attr : xxxx xxDP
P : Орієнтація паперу
0 : Книжкова / портретна орієнтація (Portrait)
1 : Альбомна орієнтація (Landscape)
D : Напрямок верстки тексту
0 : Горизонтальний напрямок тексту (ліворуч-праворуч)
1 : Вертикальний напрямок тексту (згори-вниз)

Параметри прямокутника сторінки та полів визначають область верстки тексту. При роздрукуванні або відображенні сторінка форматується згідно з вказаними межами.

Мал. 14 : Формат сторінки та поля

Сегмент полів сторінки (Page Margins Fusen / SUBID 1):

Змінює значення верхнього, нижнього, лівого та правого полів для наступних сторінок. 

LEN  :  10
SUBID:  1
ATTR :  UB      -               -- (Зарезервовано)
DATA :  UH      top             -- Верхнє поле
        UH      bottom          -- Нижнє поле
        UH      left            -- Ліве поле
        UH      right           -- Праве поле

Якщо для якогось із полів вказано значення 0xFFFF, поточний розмір цього поля залишається без змін.

Мал. 15 : Макет полів сторінки

Сегмент колонкового макета сторінки (Page Columns Fusen / SUBID 2):

Визначає багатоколонкову верстку тексту (кількість колонок та проміжки між ними). 

LEN  :  4, 6
SUBID:  2
ATTR :  UB      column          -- Кількість колонок та режим (column)
DATA :  UH      colsp           -- Міжколонковий інтервал
      [ UH      colline         -- Стиль розділювальної лінії ]
column : Kxxx CCCC
CCCC : Кількість колонок (від 0 до 15).
Значення 0 або 1 означає одноколонкову верстку.
K : Режим вирівнювання колонок
0 : Колонки однакової ширини.
1 : Колонки змінної ширини.
colsp:
Відстань (проміжок) між сусідніми колонками.
colline:
Стиль розділювальної лінії між колонками (опціональний параметр). 
      DIWW KKKK
D : Напрямок розділювальної лінії
0 : Суцільна лінія
1 : Пунктирна лінія
I : Пропорція товщини
0 : 100%
1 : 50%
W : Товщина лінії
0 : Тонка (1 піксель)
1 : Середня
2 : Товста
3 : Подвійна лінія

При використанні багатоколонкової верстки код розриву колонки (символ керування 0x0B) примусово переносить обробку наступного тексту у верхню частину наступної колонки. Наприклад, для 3-колонкового макета (column = 3) символ 0x0B виконує послідовний перехід між колонками на поточній сторінці.

Мал. 16 : Багатоколонковий макет

Якщо сторінка завершується або вставляється розрив сторінки, система може автоматично вирівнювати висоту тексту в усіх колонках (балансування колонок), щоб вони мали однакову довжину.

Сегмент колонтитулів сторінки (Page Header / Footer Fusen / SUBID 3):

Визначає верхні та нижні колонтитули сторінки (до 16 різних типів колонтитулів). Дозволяє задавати вирівнювання (по центру, зліва, справа), номери сторінок, поточну дату та верхній/нижній розмежувальний кант. 

LEN  :  Змінна
SUBID:  3
ATTR :  UB      attr            -- Тип колонтитула (верхній/нижній, парна/непарна сторінка)
DATA :  UB      data[]          -- Дані або текстовий рядок колонтитула
attr: xxPP NNNN
NNNN : Номер слота колонтитула (від 0 до 15).
PP : Сторінки застосування
0 : Відображати на всіх сторінках (парних та непарних)
1 : Відображати тільки на непарних сторінках
2 : Відображати тільки на парних сторінках
data :
Вміст колонтитула. Може містити звичайний текст, змінні автотексту (номер сторінки, дата) та вкладені вкладки форматування.
Мал. 20 : Накладання колонтитулів

Сегмент фонового накладання / водяного знака (Paper Overlay Fusen / SUBID 4):

Визначає фонові бланки, сітки або зображення водяних знаків, які накладаються на сторінку під текстом. 

LEN  :  4
SUBID:  4
ATTR :  UB      -               -- (Зарезервовано)
DATA :  UH      overlay         -- Бітова маска вибору фонового бланка
overlay :
Бітова маска шарів фонового накладання. Кожен увімкнений біт "1" активує відповідний фоновий бланк.

Сегмент прямокутної області верстки / фрейму (Text Area Fusen / SUBID 5):

Обмежує область верстки тексту заданим прямокутником area у межах сторінки. 

LEN  :  10
SUBID:  5
ATTR :  UB      attr            -- Атрибути області / фрейму
DATA :  RECT    area            -- Прямокутні координати області
attr : APKx HHVV
A : Тип координат
0 : Відносно полів сторінки
1 : Абсолютні координати сторінки
P : Обтікання / позиціонування
0 : Вкладка діє всередині фрейму
1 : Вкладка діє зовні (обтікання текстом)
K : Кадрування
0 : Обізати текст по межі прямокутника (Clip)
1 : Переносити текст по словах (Wrap)
HH, VV : Горизонтальне та вертикальне вирівнювання фрейму
area :
Описовий прямокутник області верстки.

3.5.3 Сегменти лінійки та форматування абзаців (TS_TRULER / 0xA1)

Сегмент лінійки TS_TRULER регулює міжрядковий інтервал, вирівнювання тексту у межах абзацу, ліві та праві поля, абзацні відступи, поля табуляції та сітки колонок.

Мал. 25 : Форматування лінійки та полів

Сегмент міжрядкового інтервалу (Line Spacing Fusen / SUBID 0):

Задає висоту та інтервал між сусідніми рядками тексту. 

LEN  :  4
SUBID:  0
ATTR :  UB      attr            -- Прапорці режиму інтервалу (attr)
DATA :  SCALE   pitch           -- Значення міжрядкового інтервалу
attr : Dxxx xxxG
D : Знак інтервалу (0 = позитивний +, 1 = негативний -)
G : Тип одиниць (0 = відносно висоти шрифту, 1 = абсолютний крок у SCALE)
pitch :
Значення міжрядкового інтервалу в одиницях SCALE.

Сегмент вирівнювання абзацу (Paragraph Alignment Fusen / SUBID 1):

Задає режим горизонтального вирівнювання тексту в абзаці. 

LEN  :  2
SUBID:  1
ATTR :  UB      align           -- Режим вирівнювання

  align:
        0: Вирівнювання по лівому краю (Left)
        1: Вирівнювання по центру (Center)
        2: Вирівнювання по правому краю (Right)

Сегмент відступів та табуляції абзацу (Paragraph Indents & Tabulation Fusen / SUBID 2):

Визначає ліве та праве поля абзацу, абзацний відступ першого рядка (Indent) та позиції табуляції. 

LEN  :  Змінна
SUBID:  2
ATTR :  UB      attr            -- Прапорці режиму відступів (Rxxx xxPP)
DATA :  SCALE   height          -- Висота базового рядка
        SCALE   pargap          -- Інтервал між абзацами
        H       left            -- Ліве поле абзацу
        H       right           -- Праве поле абзацу
        H       indent          -- Абзацний відступ першого рядка (Indent)
        H       ntabs           -- Кількість позицій табуляції
        UH      tabs[]          -- Масив позицій табуляції (ntabs елементів)
attr : Rxxx xxPP
R : Режим позиціонування (0 = відносно полів сторінки, 1 = абсолютні координати)
P : Режим успадкування (0 = стандартна лінійка, 1 = успадкувати попередню, 2 = перевизначити)
height, pargap :
Висота базового рядка та інтервал між сусідніми абзацами.
left, right, indent :
Лівий відступ, правий відступ та відступ першого рядка абзацу.
ntabs, tabs[] :
Кількість та масив координат позицій табуляції.
Мал. 28 : Форматування табуляції

Специфікація лінійки абзацу та сітки полів (Specified Paragraph Ruler & Field Tabulation Fusen / SUBID 3):

Повна специфікація лінійки абзацу, яка задає висоту рядків, міжабзацний проміжок, межі полів, абзацний відступ, а також налаштування окремих полів/колонок та ліній сітки табуляції. 

LEN  :  Змінна
SUBID:  3
ATTR :  UB      attr            -- Атрибути лінійки (Rxxx xxPP)
DATA :  SCALE   height          -- Висота базового рядка
        SCALE   pargap          -- Інтервал між абзацами
        UH      line            -- Формат та стиль лінії сітки (line)
        H       nfld            -- Кількість полів/колонок табуляції (nfld)
      [ -- Масив специфікацій полів (nfld елементів) --
        UH      left            -- Ліве поле поля/колонки
        UH      right           -- Праве поле поля/колонки
        UH      margin          -- Абзацний відступ першого рядка / вирівнювання
        UH      f_attr          -- Атрибути поля (HxWW KKKK xxxx xAAA)
      ]
attr : Rxxx xxPP
R : Режим позиціонування
0 : Відносні відступи від полів сторінки
1 : Абсолютні координати сторінки
P : Режим джерела лінійки
0 : Стандартна лінійка за замовчуванням
1 : Успадкувати параметри попередньої лінійки
2 : Явно вказана користувацька лінійка
3 : Спеціальний табличний формат
height :
Висота базового рядка абзацу в одиницях SCALE.
pargap :
Додатковий інтервал між сусідніми абзацами у тип SCALE.
line : DIWW KKKK
D : Напрямок лінії
0 : Суцільна лінія
1 : Пунктирна лінія
I : Масштаб товщини
0 : 100%
1 : 50%
W : Тип лінії
0 : Без лінії (ігнорується)
1 : Тонка лінія
2 : Середня лінія
3 : Товста лінія
K : Стиль гарнітури / сітки (0..15)
nfld :
Кількість полів/колонок табуляції на лінійці.
  • Якщо nfld > 0: вказує точну кількість полів/колонок у масиві.
  • Якщо nfld = -1..-3: задає заздалегідь визначений табличний формат сітки (значення height, pargap, line береться з пресету).
left, right, margin :
Ліве та праве поле колонки, а також значення абзацного відступу першого рядка (Indent). 
  margin значення:
    Вирівнювання по лівому краю    -- Використовує значення margin як абзацний відступ (Indent)
    Вирівнювання по центру          -- Ігнорується (центричний відступ)
    Вирівнювання по правому краю    -- Ігнорується
    Вирівнювання по ширині (Justify)-- Використовує margin як відступ
f_attr : HxWW KKKK xxxx xAAA
H : Дозвіл розриву колонки / переносу
0 : Заборонено розрив
1 : Дозволено розрив
W, K : Товщина та стиль ліній розмежування полів
AAA : Вирівнювання вмісту в полі
0 : Вирівнювання по лівому краю (Left)
1 : Вирівнювання по центру (Center)
2 : Вирівнювання по правому краю (Right)
3 : Вирівнювання по ширині (Justify)
4 : Десяткова табуляція
