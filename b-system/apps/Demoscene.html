概要と音響視覚シム原理 (Overview & Audio-Visual Shim Principle)

リル・キューブ 64（Lil Cu 64）は、B-System仕様に準拠したC99/OpenGL ES 1.1ネイティブ実装のリアルタイム3Dデモシーンです。 Webフロントエンド（index.html）のThree.js/WebAudio版実装と1:1の数理モデルを共有し、4次元超球面 S³ ⊂ ℝ⁴ から2次元リーマン球面 S² へのファイバー束写像 p: S³ → S² をリアルタイムパラメトリック演算して描画します。

本システムの中核思想は「音響視覚シム原理（Audio-Visual Shim Principle）」にあります。従来のゲーム開発における「別個に録音されたWAVファイルをアニメーションイベントにアタッチする」手法を完全に廃し、キャラクターのすべての3D運動学的動作（キネマティクス）を確定論的DSP合成関数「音響シム（Sound Shim）」に1対1で直結しています。外部PCMサンプルファイルは一切不要（0バイト資産）であり、100KB以下の埋め込みコードで48音ポリフォニックの壮大なオーケストラ・ジャズ・インダストリアル音響を即時生成します。

Chebyshev 非線形飽和歪み (WaveShaper) C(x) = [((3 + k) · x · 20°) / (π + k·|x|)] / maxVal
(20° = 20π / 180, 歪み係数 k = 25)		 デジタルクリッピングを排し、偶数・奇数倍音を音楽的に励起する真空管ウォームサチュレーション。shimIndustrialBass, shimCyberLead, shimIndustrialKick の重厚な音圧基盤。

3.4 形式的数理定理とライフサイクル保証 (Formal Theorems & Lifecycle Proof)

定義 1: BTRON Sound Shim 互換性規約 (Compatibility Contract)

関数 S(t₀, …) が正当な BTRON Sound Shim であるための必要十分条件：
1. 無状態性 (Stateless): AudioContext および登録配列以外のグローバル音響状態を読み書きしない。
2. 自己完結性 (Self-contained): 単一の同期呼出し内で全 AudioNode を生成・接続・起動する。
3. GC回収可能性 (Garbage-collectible): 生成した全オシレータ／音源ノードを registerTrackOsc() に登録する。
4. 例外沈黙性 (Silent-on-error): 本体全体を try { … } catch(e) {} で防護し、例外を外部に波及させない。

定理 1: ゼロメモリリーク定理 (Zero Memory Leak Theorem)

全シムが互換性規約を充足するとき、任意のトラック停止時刻 tstop において stopAllTracks() の呼出しは以下を保証する：
limt → tstop⁺ |𝒩(t)| = 0 （ここで 𝒩(t) は生存する AudioNode の集合）。
証明骨子: stopAllTracks() は登録された全ノードに対し osc.stop() と osc.disconnect() を実行し追跡配列をクリアする。参照カウントが即座にゼロとなり、JavaScript V8 / JSC GC（またはC99メモリマネージャ）によって完全に解放回収される。［証明終］

新音色の同定・拡張には短時間フーリエ変換（STFT）を採用し、スペクトログラム X(m, k) = ∑ [n=0..N−1] x(n + mH) · w(n) · e−j 2π kn / N から倍音構造・共振尖鋭度・ノイズ比率を逆算してシムへ符号化します。

6. 空間音響・トラッカー調時・適応型機構 (Spatial Audio, Tracker & Adaptive Gameplay)

3D音響空間、トラッカーグリッドの数学的調時式、およびプレイヤー入力の量子化アーキテクチャ。
"Spatial panning laws, tracker timing equations, 8-channel voice allocation, and interactive quantization."

  • 3D空間音響と定位則: リスナーはカメラ座標 (0, 0.08, 9.2) に位置し、水平パン角 p ∈ [−1, +1] に対する等パワー定位則 GainL = cos(π/₄·(p + 1)), GainR = sin(π/₄·(p + 1)) を適用。距離減衰 dref / (dref + max(0, d − dref)) および大気高域吸収（2kHz以上カット）をリアルタイム計算。
  • トラッカー数学的調時式: Tbeat = 60 / BPM, Tbar = Tbeat × 拍数, T8th = Tbeat / 2, T16th = Tbeat / 4。
  • 8チャンネルボイスマトリクス: Ch1(ベース/サブ) · Ch2(ドラム/打楽器) · Ch3(和声パッド) · Ch4(主旋律リード) · Ch5(対位法管楽器) · Ch6(アルペジオ/FX) · Ch7(高域チャイム) · Ch8(アンビエント)。
  • 対話型入力の16分音符量子化 (Input Quantization): プレイヤーがSpaceキー等を押下した際、入力時刻 tin は直後の16分音符境界 ttrigger = tbar + ⌈(tin − tbar) / T16th⌉ · T16th に即座に吸着。演奏と操作が絶対に不協和を起こさない即興音楽メカニクスを実現。
  • 動的ステムミキシング (Dynamic Stem Mixing): プレイヤー体力満全時は全音量、被弾時は800Hzローパス ＋ 心音キックドラムが強調され、無敵スター獲得時は shimDance アルペジオが +3dB で前面浮上。

7. 全4ステージ楽曲仕様とゲームプレイ (Detailed Level & Composition Architecture)

Lil Cube 64 に収録された全4ステージの音楽諸元、プロシージャル編成、および楽曲と完全同期したゲームプレイ仕様。
"Comprehensive level design, musical parameters, instrumentation, and narrative mechanics for Levels 1 to 4."

Level 1: 氷晶雪原の疾走 (Crystalline Snowfield Speedrun)

楽曲: 鐘のキャロル (Carol of the Bells) テンポ: 168 BPM (Vivace 3/4拍子) 調性: ホ短調 (E Minor) 小節数: 24小節 (~25.8秒) 音量バランス: t1Vol = 0.78

プロシージャル編成: shimDing（G5-F#5-G5-E5 の象徴的4音モティーフ）、shimWaddle（E2-B2-E3 軽快な8-bitベース）、shimPulseSquash（B5-C6 高音リード）、shimDance（Em-D-C-B7 上を舞う16分星屑アルペジオ）、shimFloat（FM和音パッド）、チップドラムキット、shimSaxFlute（疾走フルート対位旋律）。

ゲームプレイ設計: マウント・ビートロンの凍結斜面で雪崩とともに覚醒。3/4拍子のワルツのリズムに合わせて氷のレールを滑走し氷河のクレバスを跳躍。雪の結晶を獲得するたびに16分音符アルペジオが鳴り響き、冬の神殿ポータルへと飛び込みます。

Level 2: 夜行バイユーと蛍の沼 (Nocturnal Bayou & Neon Bog)

楽曲: 今田勝 "Green Caterpillar" (1975 TBM) テンポ: 98 BPM (Swinging 4/4拍子) 調性: ニ短調ブルース (D Minor Blues) 小節数: 10小節 (~26.0秒) 音量バランス: t2Vol = 1.0

プロシージャル編成: shimFloat（今田勝スタイルのフェンダー・ローズ・エレピ＆ピアノ）、shimWaddle（福井五十雄直伝のアコースティック・ウォーキングアップライトベース）、shimGuitar（渡辺香津美 Gibson L-5 クリーンジャズギター）、フルジャズドラム（小原哲次郎ライドシンバル＆ブラシスネア）、shimPulseFrog（今村祐司クイーカ蛙擦過音）、shimSaxFlute（夜行メロディカ）。

ゲームプレイ設計: 三日月が照らす蛍光キノコと霧の沼地。クイーカの鳴き声（shimPulseFrog）が水中に隠れた足場の出現合図となり、ウォーキングベースのスイングに合わせて眠る沼の怪物の頭上を静かに飛び移るステルスアクションが展開されます。

Level 3: 黎明の天空大聖堂 (Dawn Sky Cathedral)

楽曲: 朝日のあたる家 (House of the Rising Sun / Thomas Krüger Arr.) テンポ: 76 BPM (Slow 6/8拍子, 8分=0.24s) 調性: イ短調 (A Minor) 小節数: 18小節 (~26.5秒) 音量バランス: t3Vol = 1.0

プロシージャル編成: shimGrandPiano（三倍音弦振動＋木質ハンマー打弦）、shimPianoHammer、shimPedalSwoosh、shimPedalBass（A0 27.5Hz / A1 55Hz 地響き重低音）、shimSaxFlute ＆ shimPulseSquash（エリック・バードン風の熱唱ボーカル主旋律）、左手6/8ローリングアルペジオ（Am-C-D-F-Am-E-E7）、トーマス・クリューガー式高音滝カスケード（E6からG#5）、shimDing（A6 1760Hz / E7 2637Hz 明星チャイム）。

ゲームプレイ設計: ステンドグラスに朝日が差し込む天空のゴシック廃大聖堂を登攀。波打つ6/8拍子のピアノアルペジオが雲の足場の上下浮遊と同期。第2節でオクターブフォルテが入ると大理石の巨大な鐘が揺れ動き、最後の滝カスケードが電脳次元への黄金ポータルを開放します。

Level 4: 電脳要塞コア侵入 (TRON: Ares Cyber-Grid Core)

楽曲: Nine Inch Nails "Init" (TRON: Ares OST / Trent Reznor) テンポ: 132 BPM (Industrial 4/4拍子) 調性: 嬰ヘ短調 (F# Minor) 小節数: 14小節 (~25.8秒) 音量バランス: t4Vol = 1.0

プロシージャル編成: shimIndustrialBass（WaveShaper飽和歪み16分鋸歯状波ベース）、shimCyberSynth（80sデチューン・インダストリアル金管ブラス）、shimSwarmatron（8ボイス・リボンコントローラ群発振グリッサンド）、インダストリアルドラム（重低音サブドロップキック＋ゲート金属スネア）、shimPulseBell（暗黒アンビエントドローン）。

ゲームプレイ設計: ネオンベクターグリッド内部での最終決戦。パルスする16分音符インダストリアルベースが可動レーザー防壁を制御。恐怖のスウォルマトロン（Swarmatron）のピッチベンドが鳴り響くとマザー制御コアが画面全域粒子ビームを充填。コアを撃破することで4次元ホップ束の宇宙に調和が蘇ります。

8. クリエイター・モッダー向け拡張手順 (Creator & Modder Guidelines)

BTRON音響エンジンに新規ステージや楽曲を追加する際の5ステップ標準開発手順。
"5-step procedural expansion guidelines for adding new levels, shims, and choreographies."

  • 調時定数の定義: beat = 60 / BPM, bar = beat * 拍数, eighth, sixteenth を算出。
  • 3Dキネマティクス主軸の選定: レベルのリズムを牽引するマスコット主動作（walk / float / dance / squash）を決定。
  • トラッカースコア関数の実装: window.playTrack() 内で各音響シム（shimDing, shimWaddle, shimGrandPiano 等）を小節オフセットで配置。
  • ドラマツルギー振付の登録: scheduleTrackTimeout() を用いて、フォルテシモ等の劇的展開にマスコット状態遷移（例: sing）を予約同期。
  • オーディオグラフ衛生管理の検証: 全発振器で registerTrackOsc()、全タイマーで scheduleTrackTimeout() を呼び出し、GC回収とゼロリークを保証。
