ゲームシステム（MSX） — B-MSX は、B-System ワークベンチ空間上で動作する C99 純実装の MSX / MSX2 / MSX2+ / MSX turbo R 統合エミュレーション環境です。オープンソース C-BIOS を内蔵し、TMS9918A / V9938 VDP 互換描画、PSG (AY-3-8910) 音源、MegaROM カートリッジマッパー、高速早送り（Fast-Forward）、および 3次元幾何学リアルタイム演算エンジン Geo3D をネイティブサポートします。
"Official technical specification for the B-MSX game emulation environment, cartridge subsystem, fast-forward engine, and Geo3D accelerator within B-System."

概要 (Overview)

MSX規格は、1980年代初頭にアスキーの西和彦氏とマイクロソフトによって提唱され、世界的な統一ホームコンピュータ規格として普及しました。TRONプロジェクト提唱者の坂村健教授が目指した「あらゆる機器への組込みコンピュータの普及とオープンアーキテクチャ」の思想とも深く共鳴し、日本のホビー・エンターテインメント・パーソナルコンピューティングの基盤を築きました。
B-System の B-MSX は、この歴史的遺産を最新の μITRON マイクロカーネルおよび BTRON3 ワークベンチ空間に完全統合した C99 純実装エミュレーションエンジンです。外部共有ライブラリに一切依存せず、組込み μITRON タスクスケジューラ（cre_tsk / sta_tsk）直結の 60Hz 確定論的フレーム同期駆動により、ジッターのない滑らかなゲーム描画と PSG リアルタイム音声合成を実現します。

"Standard BTRON3 cascade menu bindings, real-time cartridge swapping, and instant fast-forward controls."

4. B-System ウィンドウマネージャ統合と早送り (Window Integration & Fast-Forward)

B-MSX は独立した外部プログラムではなく、B-System のウィンドウマネージャと完全に一体化しています。
"Native BTRON window manager event dispatch, multi-window compositing, and headless screenshot automation."

  • 早送り (Fast-Forward) アーキテクチャ: msx_app_fast_forward(int frames) により、描画遅延を伴うことなく CPU 命令サイクルおよび VDP レジスタ更新のみを任意のフレーム数（450〜900 フレーム）高速進捗。C-BIOS 初期化待機をスキップし、瞬時にタイトル画面・ゲーム本編に到達します。
  • 独立 μITRON タスク駆動: msx_task がバックグラウンドタスクとして独立稼働し、ウィンドウメッセージキューをブロックすることなく 60fps でフレームを更新。
  • ゼロコピー描画: VDP の 256×212 ピクセルバッファから B-System の GDEV フレームバッファへダイレクトスケーリング転送。
  • 自動テスト＆スクリーンショット自動抽出: src/tools/capture_screens.c により、ヘッドレス環境で実機描画パイプラインを起動し、カートリッジ画面およびメニュー展開状態をピクセルパーフェクトに PNG 抽出。

5. 音源の二つの設定 — Rigour と Subtle (Two Synthesizer Settings)

カートリッジが鳴らしているのは Rigour です。Subtle は、同じ音色の近くに譜面を書くための B-Sound 設定で、tronMSX にはリンクされません。
"Rigour is the chip path the window plays. Subtle is a lilcu64 score sheet and does not write the PSG or the OPLL."

詳細な数値は doc/txt/MSX-SOUND.txt 第5節、および B-Media の MSX 仕様 2.6 と同じです。

声部 Rigour（再生中のチップ） Subtle（B-Sound 譜面。再生パスではない）
送り 17 / 17 / 16 ms。キュー 17,640 バイトで 1 ブロックを落とす。スピーカのコンデンサはポンプ内だけ（約 14 Hz）。整数ミックス。ソフトニーは使わない。 44,100 Hz。master_soft_clamp は B-Sound 側に残す。パンは 0。
PSG 1,789,772 Hz。f = 1789772 / (16·TP)。16 段階は 0, 51, 57, 64, 71, 80, 90, 101, 113, 127, 143, 160, 180, 202, 227, 255 を左へ 5。15 は 8160。形状 0x0B は最大を保持、0x0F は無音を保持。 矩形 PULSE、振幅 0.22、減衰 0.18 秒。ノイズは振幅 0.08、減衰 0.12 秒。エンベロープは同じ 16 段階を 0.22/255 に縮め、WA_LIN でつなぐ。
