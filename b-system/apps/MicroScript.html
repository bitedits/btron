マイクロスクリプト（MicroScript） — 超漢字（Cho-Kanji／パーソナルメディア）の手続型・ブロック構造・マルチスレッド・アクター（役者）指向ハイパーメディア言語を再現する、B-System組込みのステージ解釈系。
"A deterministic, allocation-free runtime for a C-family, block-structured, multithreaded hypermedia language with actor (SEGMENT), scene (SCENE) and procedure (SCRIPT) constructs."

概要 (Overview)

マイクロスクリプト（MicroScript）は、1990年代の超漢字／MicroEngineで導入されたハイパーメディア記述言語です。C言語族に由来する手続型・ブロック構造・大文字小文字非区別の言語であり、明示的なブロック終端子（ENDxxx／和名「〜おわり」）で構文を閉じます。花括弧は用いません。処理モデルはアクター指向のマルチスレッドで、SEGMENT（役者）が画面上のアクティブ要素、SCENE（シーン）が表示場面、SCRIPT（手続き）が呼び出し可能な処理単位に対応します。
MicroScript の日本語ローカライズ後継がプログラミング言語Tであり、公式のコマンド名対応表は英語キーワード（MicroScript 由来）と和名キーワード（T）を 1:1 で対応づけます。両言語で英日どちらのキーワードも使用可能です。本ページはパーソナルメディア（PMC）公式マニュアル（chokanji.com／超漢字V）に準拠した言語リファレンスを示します。
本実装（src/chokanji/microscript.c）は NASA JPL「Power of 10」指針に厳密準拠し、初期化後の動的メモリ確保を一切行わず、字句解析・評価・描画の全ループに上限を課した確定論的エンジンとして提供されます。 "A C-family, case-insensitive, brace-free language with explicit ENDxxx block terminators and an actor-based (SEGMENT/役者) multithreaded model. Programming Language T is its Japanese-localized successor; both accept English and Japanese keywords."

2. 型・演算子・文法 (Value Types, Operators & Grammar)

MicroScript／プログラミング言語T の基本表記規則。型は1文字の種別コードで宣言し、代入は矢印 ← または =、コメントは行頭 #、ブロックは ENDxxx で閉じます（花括弧なし）。
"Single-letter type codes, arrow assignment, # line comments, explicit ENDxxx terminators, no braces, no pointers."

8. 使用例 (Usage Example)

公式構文（プログラミング言語T 相当の英語キーワード）で記述した手続きと役者の例。
"A representative procedure and actor written in the official grammar (English keywords, ENDxxx terminators)." 

# グローバル変数と手続きの定義（公式構文）
VARIABLE count:I
VARIABLE label:S

SCRIPT show_count(n:I)
    表示("count = %d", n)
    IF n > 0 THEN
        SET count = n
    ELSE
        SET count = 0
    ENDIF
    EXIT count
END

# 役者（アクター）定義と並列起動
SEGMENT actor1
    MOVE 120, 80
    APPEAR "stage1.img"
END

9. 設計原則 (Design Principles — Power of 10)

本エンジンは NASA JPL「Power of 10」安全クリティカル規則を C99 アプリケーション層で適用しています。
"Safety-critical coding rules applied to the application layer in strict C99."

原則適用方法 (Enforcement)
固定メモリフットプリント初期化後の動的確保ゼロ。全状態を静的配列 g_ms 内で保持。
有界ループ字句・評価・描画の全走査に MS_LOOP_BOUND 等の上限を適用。
クライアント局所座標描画・命中判定は (0,0)〜(w,h) のウィンドウ内空間に限定。
確定論的解釈行指向の逐次評価と範囲ガードにより、入力に対する挙動が再現可能。
