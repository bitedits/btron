管弦楽（Orchestra） — セッションは /SYS/orchestra.orch の 73408 バイトです。プログラムは 32、SoundFont はありません。ホールは一つ。インサートの種類は八つで、一つの種類は八つまで、トラックには二つまでです。テンプレートは Rock、Classic、Orchestra の三つです。
"The session file is 73408 bytes. Thirty-two programs, no SoundFont, one hall, eight insert types, three templates."

概要 (Overview)

窓は七つです。ステージ、アレンジ、ピアノ、スコア、ミックス、インサート、アバウト（520×270）。メニューはステージだけに描きます。見出しは六つです。ファイル、コンサート、シーン、トラック、装置、ウィンドウ。
"Seven windows. The menu bar is on the stage only, with six headers. About is 520 by 270."

1. 九つの要素 (Nine Elements)

コンサートのグラフは九スロットです。midisrc、queue、midiroute、shimsynth、audioconvert、tee、audiomixer、volume、virtiosndsink。ファクトリに fluidsynth はありません。音源は 32 プログラムの手続き型シムです。
MIDI の配送は INPUT 面の 500 µs 以内に戻ります。「0.2 ms 未満」と言えるのはこの一文だけです。聞こえる遅れは、キューに残ったフレーム数をサンプルレートで割った値です。
量子は Q=32、締め切りは T です。ホスト周期は 1024 フレームです。48000 Hz では 21.3 ms、44100 Hz では 23.2 ms。サンプルレートはこの二つだけです。
"Nine slots, shimsynth, no SoundFont. MIDI dispatch returns inside 500 µs. Heard delay is the measured queue. Q is 32. The host period is 1024 frames."

2. メニュー (Menu)

ファイルは新規、開く、上書き保存、SMF の読み書き、WAV の書き出し、閉じる。コンサートは再生、停止、録音、パニック、クリックと三つのテンプレート。シーンは送信とオクターブ。十六のシーンはステージの格子です。トラックは追加、削除、分割、ベロシティ、チャンネル、リターン。装置はバッファ（Q=32 とホスト 1024 を表示するだけ）、DSP、診断、タイムコード形式の保存、クロック、ポート、測定した遅延。ウィンドウは七つの窓を開きます。
"File, Concert, Scene, Track, Device, Window. WAV export writes /SYS/orchestra.wav and nothing reads it back. SMF is /SYS/orchestra.mid."
