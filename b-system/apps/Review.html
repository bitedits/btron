概要 (Overview)

差分校正（Review）は、B-Systemの仕様に準拠したC99実装アプリケーション。TAD実身バイナリおよびソースコードの視覚的差分比較・校正アプレット。
"Official technical specification for the Review application within the B-System operating environment."

1. メニュー構造と操作体系 (Menu Architecture & Operations)

Review が提供する標準メニューバー構造（APP_MENU_BAR）および操作体系の仕様。
"Standard in-app menu bar hierarchy, keyboard shortcuts, and interactive command bindings."

2. 機能仕様とアーキテクチャ (Functional & Architecture Specifications)

Review アプリケーションの内部構造、データモデル、およびシステムコール仕様。
"Internal architectural components, memory models, and system call bindings."

コンポーネント・機能名 動作概要と機能仕様 (Functional Specification) 技術仕様・C99構造体 (C99 Implementation)
PDFベクトル描画 PDF 1.4のコンテンツストリーム（BT/ET、Tf、Tm、Td、Tj、m/l/c/h、re、w、RG/rg/G/g、S/s/f/b）をDP線分・矩形・TRONフォントへと直接ラスタライズ。 pdf_reader_render_page(), pdf_exec_stream()
インアップメニューバー クラシック3Dベベルスタイルのヘッダーとドロップダウンプレート。マウスホバーによるヘッダー滑空（Glide）、外側クリック自動消去、ステータス右端表示（頁数・倍率・付箋数）。 APP_MENU_BAR, app_menu_paint_bar()
標準スクロールバー BTRON伝統の3Dステッパー矢印（▲/▼、◄/►）とエレベータ親指（Thumb）。マウスドラッグによる連続スクロール、トラッククリックによる半画面ページジャンプ、方向キー（↑↓←→）連動。 paint_scrollbar_v(), paint_scrollbar_h()
マージナリア欄 (Marginalia) ウィンドウ幅 640px 以上で右側に 230px の校正メモレールを自動展開。頁番号、著者、タイムスタンプ、ゴールドのピンバッジ付きカード表示。 ReviewAnnotation, app->annos[]
About ダイアログ 親ウィンドウ連動のNano About Box（420×170px）。エンボスアイコン、タイトル、Secure PostScript/ISO 32000エンジン情報、Cleanroom Working Group帰属表示、OKボタン。 open_review_about_window(), app_menu_create_about_dialog()
