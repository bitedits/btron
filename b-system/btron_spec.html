Специфікації GUI, DP та VOBJ

Розділ 4: Графічні примітиви DP

Графічний рушій Display Primitives (DP) у B-System спроектований як високоефективна бібліотека для рендерингу 2D/3D-графіки безпосередньо у VirtIO фреймбуфер з подальшим передаванням на хостовий бекенд SDL2.

4.1 2D примітиви

  • gd_rect, gd_round_rect — малювання прямокутних областей та областей із закругленими кутами.
  • gd_draw_text — рендеринг векторних та растрових шрифтів із підтримкою TRON Code.
  • gd_clip — маскування та малювання у геометричних регіонах відсікання.

4.2 FFT Спектрограми та Waterfall

Для завдань радіотехніки та аналізу сигналів DP містить алгоритми швидкого виводу спектрограм:

  • gd_draw_spectrum_line — векторний графік спектра потужності сигналу (FFT) зі згладжуванням Wu.
  • gd_blit_waterfall_scroll — скролінг растрової палітри Waterfall на 1 рядок униз (кольори HSL dBm).

4.3 Векторний Wireframe (TRON/NetWars)

Векторний рушій B-System підтримує неонову каркасну графіку у сучасному виконанні:

  • gd_wireframe_grid — малювання 3D перспективної сітки (TRON Lightcycles Grid).
  • gd_draw_wireframe_mesh — растеризація 3D векторних каркасів (кораблі NetWars).
  • gd_glow_line — неонові лінії з градієнтним розмиттям свічення (glow buffer).

Розділ 5: Менеджер Вікон

Графічний інтерфейс B-System наслідує класичний ретро-дизайн операційної системи Cho-Kanji та BTRON із бірюзовою робочою зоною, верхньою статус-панеллю та ієрархічним менеджером вікон.

Менеджер вікон забезпечує:

  • Створення вікон із заголовками, рамками, смугами прокручування та кнопками згортання.
  • Надсилання подій віконної системи (WND_EVENT) процесу-додатку.
  • Синхронізація оновлень вікна із virtio-gpu та host SDL2 window manager.

Розділ 6: Об'єктна Модель VOBJ

B-System повністю імплементує об'єктну модель BTRON. Замість ієрархічного дерева каталогів пропонується гіпер-текстове середовище:

  • Реальні об'єкти (Real Objects): дані, що зберігаються в кабінетах накопичувачів без розширення файлу.
  • Віртуальні об'єкти (Virtual Bodys): візуальні посилання (ярлики), які можна вбудовувати в тіло інших документів. Документ може містити текст, малюнки, спектрограми сигналів чи Wireframe 3D сценарії.
