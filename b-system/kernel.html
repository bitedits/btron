Архітектура Ядра B-System

Розділ 1: Вступ та Архітектура B-System

Операційна система B-System побудована за модульною мікроядерною архітектурою 2026 року. B-System ізолює керування обладнанням, обробку радіосигналів, графіку та об'єктне сховище у незалежні сервери (System Planes), які взаємодіють через безблокувальні черги повідомлень.

Головна мета проекту — забезпечення нульової затримки реального часу для вбудованих радіотехнічних систем (SDR), DSP обробки сигналів та віртуалізованих систем під керуванням гіпервізорів seL4 та Synrc VE OS.1 з виключно відкритим кодом (MIT/BSD).

Розділ 2: Ядро Мікроконтролера µITRON

Ядром реального часу B-System виступає витісняючий планувальник, повністю сумісний зі специфікацією µITRON:

  • Багатозадачність реального часу (Deterministic Scheduling): Витісняюче планування із гарантованим верхнім порогом затримки перемикання контексту для тасків обробки FFT та IQ-потоків.
  • Синхронізація без блокувань: Легкі семафори (sem), прапорці подій (flg) та безблокувальні кільцеві буфери (Virtqueues), оптимізовані под багатоядерні системи (SMP RISC-V 64 / ARM64 / x86_64).
  • Обмін радіотелеметрією: Високоефективні FIFO-потоки для міжпроцесної взаємодії через virtio-console та virtio-net.

Розділ 3: Менеджер Ядра BTRON

Менеджер ядра BTRON (BTRON Kernel Manager) працює поверх ядра µITRON та виконує роль координатора системних ресурсів. Він надає вищим шарам API для керування життєвим циклом додатків, виділення великих пулів пам'яті (Memory Segments) та обробки міжпроцесної взаємодії через інтерфейси LOWLIB.

Розділ 9: Віртуалізація VirtIO & Synrc VE

B-System розробляється з першокласною підтримкою апаратної віртуалізації. Вся взаємодія з хостом здійснюється через специфікацію VirtIO 1.2:

  • Synrc VE Host Matrix (macOS, Linux, FreeBSD, seL4): Детальний опис хостових середовищ та сумісності дивіться у спеціалізованому розділі Специфікація VirtIO & VE Matrix.
  • VirtIO-GPU / SDL2 Blitter: Апаратно-прискорений рендеринг 2D-примітивів, векторної wireframe-графіки (TRON / NetWars) та каскадів Waterfall.
  • VirtIO-Block / NVMe: Швидкісний доступ до дискових об'єктних кабінетів BTRON FS.
  • VirtIO-Console & VirtIO-Net: Потокова передача IQ-даних радіоізоляції та вивід системних логів.
  • seL4 Microkernel Handoff: Запуск B-System як окремого домену безпеки (Protection Domain) з повною ізоляцією пам'яті за стандартами NIST 53.
