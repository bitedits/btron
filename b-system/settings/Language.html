4. 入力方法の使い方 (How to Use the Input Methods)

B-Systemの言語入力基盤は、5歳のお子さまから研究者・専門家まで、 日本語・チベット語・英語をワンキーで自然に切り替えながら使えるよう設計されています。
"Designed for every user from age five to one hundred: seamless, instant switching between Japanese, Tibetan, and English input with a single keystroke."

4-1. 日本語入力（Mozc かな漢字変換）

基本の流れ：
① F10 キーを押すか、ウィンドウ右下の [TIP: あ (F10)] バッジをクリックして ひらがなモード（あ）にします。
② ローマ字でそのまま打ちます。たとえば hotoke と入力すると、 カーソル直下に下線付きで 「ほとけ」 と表示されます（未確定文字列）。
③ スペースキー を押すと辞書候補の一覧が開きます： 「仏」「ほとけ」「仏さん」「仏様」など。
④ スペースキーまたは矢印キーで目的の候補を選び、Enter で確定します。
⑤ F6〜F9 のファンクションキーで、読みをひらがな・カタカナ・英字に即座に変換できます。

よく使うキー操作：
 Space → 変換候補を開く   Enter → 確定   Esc → 未確定をキャンセル   F10 → 入力モード切替（JP あ ↔ EN）

4-2. チベット語入力（Extended Wylie / EWTS）

ASCIIキーボードでチベット文字を入力する：
① F8 を押してチベット語モード [TB བོད] に切り替えます。
② Extended Wylie（EWTS）のローマ字表記でそのまま打ちます。
 例：cho と打つと候補一覧が開き、以下のような単語が提示されます：
  • ཆོས（chos — 法 / ダルマ / 真実）
  • ཆོས་ཉིད（chos nyid — 法性 / dharmatā）
  • ཆོས་སྐུ（chos sku — 法身 / dharmakāya）
  • ཆོས་ཐམས་ཅད（すべての法 / sarvadharmāḥ）
③ Tab またはスペースで候補リストを開き、矢印キーで選んで Enter で確定します。
④ 重なり文字（སྟ、གྲ など複合スタック）も EWTS 表記から自動サブジョイニングされます。

主な EWTS 単語例（辞書収録）：
 oM → ཨོཾ（オーム / OṂ）  sangs_rgyas → སངས་རྒྱས（仏陀 / Buddha）  snying_rje → སྙིང་རྗེ（慈悲 / karuṇā）
 stong_pa_nyid → སྟོང་པ་ཉིད（空性 / śūnyatā）  shes_rab → ཤེས་རབ（般若 / prajñā）
