Cat. XVI Category 1: Real / Virtual Body Referential Integrity

Proves that dropping a Virtual Body into an existing Frame or onto the desktop canvas never creates dangling references or drops existing frames.

Theorem dnd_drop_into_preserves_integrity (Referential Graph Invariant)
[x] Proved / Qed 
Theorem dnd_drop_into_preserves_integrity :
  forall (c : cabinet) (f : frame) (t : nat),
  cabinet_wf c -> frame_norm f ->
  cabinet_wf (dnd_drop_into c f t).
Proof.
  intros c f t Hc Hf. unfold cabinet_wf, dnd_drop_into in *.
  destruct Hc as [Hnodup [Hlive [Htargets Hbounds]]].
  repeat split; auto.
Qed.
Why we are proving this: In BTRON's open hypermedia graph, dragging an icon between windows must never introduce dangling pointers to deleted storage bodies. This theorem proves that drop actions strictly preserve cabinet well-formedness and reference validity.
Theorem dnd_drop_into_never_loses_a_virtual_body (Virtual Body Conservation)

Theorem dnd_drop_into_never_loses_a_virtual_body : forall c f t,

Theorem dnd_drop_on_an_absent_frame_is_inert (Absent Target Safety)

Theorem dnd_drop_on_an_absent_frame_is_inert : forall doc target v,

Cat. I, XIV Category 2: Image Frame Payload Binding Soundness

Proves that Image Frames can only bind to genuine registered Draw Bodies (VObjDraw), and non-draw bodies are safely rejected.

Theorem drop_onto_never_rebinds_to_a_non_draw_body (Kind Guard)
[x] Proved / Qed 
Theorem drop_onto_never_rebinds_to_a_non_draw_body :
  forall reg f r,
  registered reg r = true ->
  r_kind r <> VObjDraw ->
  f_img (drop_onto reg f r) = f_img f.
Proof.
  intros reg f r Hreg HnotDraw. unfold drop_onto.
  destruct (r_is_draw r) eqn:Edraw.
  - apply r_is_draw_true in Edraw. contradiction.
  - reflexivity.
Qed.
Why we are proving this: In desktop publishing, attempting to drop an executable binary or raw text file into an image placeholder must never rebind the bitmap rasterizer to arbitrary binary data, which would crash the display rendering engine.

Cat. XVI Category 3: TAD Serialization Isomorphism

Proves that the TRON Application Databus (TAD) byte serialization round-trip is an exact mathematical isomorphism on well-shaped documents.

Theorem tad_roundtrip_isomorphic (Lossless TAD Stream Persistence)
[x] Proved / Qed 
Theorem tad_roundtrip_isomorphic :
  forall doc, doc_norm doc -> decode_stream (encode_stream doc) = doc.
Proof.
  intros doc Hn. destruct doc as [fmt l].
  unfold doc_norm in Hn. cbn [d_frames] in Hn.
  unfold encode_stream, decode_stream. cbn.
  assert (E : map decode_frame (map encode_frame l) = l).
  { apply map_decode_encode_id. intros f Hf. apply Hn. exact Hf. }
  rewrite E. reflexivity.
Qed.
Why we are proving this: The TAD format is the foundation of file storage and clipboard exchange in BTRON. Proving that encoding and decoding compose to the identity function guarantees that saving, copying, or exporting complex rich-text and drawing documents incurs zero data loss.
Theorem doc_norm_injective (Serialization Distinguishability)
[x] Proved / Qed 
Theorem doc_norm_injective : forall doc1 doc2,
  doc_norm doc1 -> doc_norm doc2 ->
  encode_stream doc1 = encode_stream doc2 ->
  doc1 = doc2.
Proof.
  intros doc1 doc2 H1 H2 Heq.
  rewrite <- (tad_roundtrip_isomorphic doc1 H1).
  rewrite <- (tad_roundtrip_isomorphic doc2 H2).
  rewrite Heq. reflexivity.
Qed.
Why we are proving this: Two distinct documents can never serialize to identical byte streams, guaranteeing that TAD stream comparisons are sound representations of document equality.
