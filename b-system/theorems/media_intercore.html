Cat. I Category 1: Spatial Memory Isolation & Frame Disjointness

Proves that core control blocks occupy disjoint physical memory frames, and modifying one writer slot leaves all other cores invariant.

Lemma at_w_other_w (Writer Slot Frame Axiom)
[x] Proved / Qed 
Lemma at_w_other_w : forall b i (w:writer) j,
  i <> j -> b_w (bus_w b i w) j = b_w b j.
Proof.
  intros b i w j H. unfold bus_w. apply upd_other. exact H.
Qed.
Why we are proving this: In multicore systems without memory management units between real-time cores, concurrent writes to one core's ring buffer could trash an adjacent core's cursor. This lemma proves frame isolation: modifying slot $i$ never touches slot $j \ne i$.

Lemma sub_joins_at_the_tail (Zero Stale Sector Pinning)

Lemma sub_joins_at_the_tail : forall b cl wid i,
  sub_slot b = Some i -> sub_admit b cl wid = true ->
  r_start (b_r (fst (sub b cl wid)) i) = w_enq (b_w b wid) /\
  r_cur   (b_r (fst (sub b cl wid)) i) = w_enq (b_w b wid) /\

Lemma rcv_never_yields : forall b cl rid,
