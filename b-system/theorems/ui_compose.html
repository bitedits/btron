1. Executable OCaml Oracle Model ui_compose_model.ml

The executable specification models rectangular geometry intersections, damage accumulation, 2D blits with ROP logic and key transparency, Painter's algorithm multi-layer compositing, and backbuffer damage presentation. 

type rect = { left : int; top : int; right : int; bottom : int }

type rop = ROP_COPY | ROP_OR | ROP_XOR | ROP_AND | ROP_INVERT

type surface = {
  width : int; height : int;
  pixels : int array; (* 32-bit ARGB: 0xAARRGGBB *)
}

(* btron_row_blit operational oracle *)
let btron_row_blit ~(dst : surface) ~(dst_x : int) ~(dst_y : int)
                   ~(src : surface) ~(src_x : int) ~(src_y : int)
                   ~(span : int) ~(rop : rop) : unit =
  let valid_span = min span (min (dst.width - dst_x) (src.width - src_x)) in
  if valid_span <= 0 then ()
  else
    let src_offset = src_y * src.width + src_x in
    let dst_offset = dst_y * dst.width + dst_x in
    for i = 0 to valid_span - 1 do
      let sp = src.pixels.(src_offset + i) in
      if sp <> 0 then (* 0x00000000 transparent key *)
        dst.pixels.(dst_offset + i) <- apply_rop rop sp dst.pixels.(dst_offset + i)
    done

Cat. I, IV Category 1: Rectangular Algebra & Clipping Invariants

Proves commutativity of rectangular clipping intersections, bidirectional containment, and bounding box union properties.

Theorem rect_intersect_comm : forall a b,
  rect_intersect a b = rect_intersect b a.

Theorem point_in_intersect_iff : forall x y a b,
  point_in_rect x y (rect_intersect a b) <->
  (point_in_rect x y a /\ point_in_rect x y b).
Why we are proving this: Establishes that clipping order is invariant and that a pixel is drawn if and only if it belongs to both the window viewport and the dirty damage rect.

Cat. II, VII Category 2: Invalidation Tracking & Monotonic Damage Expansion

Proves that successive calls to wnd_inval_damage_rect monotonically accumulate damage, and draining atomically clears the pending damage state.

Theorem damage_inval_monotonicity_prev : forall d r x y,
  point_in_rect x y d ->
  match accumulate_damage (Some d) r with
  | Some res => point_in_rect x y res
  | None => False
  end.

Theorem damage_inval_monotonicity_new : forall d r x y,
  point_in_rect x y r ->
  match accumulate_damage (Some d) r with
  | Some res => point_in_rect x y res
  | None => False
  end.
Why we are proving this: Prevents lost updates: whenever an application calls inval_wnd(), both the previously accumulated damage and the newly invalidated window bounds are preserved.

Cat. III, V, VIII Category 3: Bit Blitting & 2D Memory Safety

Proves that linear memory indices calculated during 2D blits remain strictly within buffer limits, pixels outside destination span are untouched, and ROP_COPY is idempotent.

  x + w <= W -> y + h <= H ->

Why we are proving this: Eliminates all potential out-of-bounds writes into VRAM or RAM backbuffers during accelerated NEON/DMA span transfers.

Cat. VI, X Category 4: Double Buffering & Hardware Presentation Soundness

Proves that presenting damage to the hardware scanout framebuffer updates exactly the damaged region from the RAM backbuffer while leaving non-damaged display pixels unaltered.

Theorem presenter_inside_matches_back : forall front back damage x y,

Theorem presenter_outside_preserves_front : forall front back damage x y,

  present_buffer_rect (present_buffer_rect front back damage) back damage x y =

Why we are proving this: Presentation correctness: guarantees zero tearing or corruption outside the active damage rectangle, and ensures repeated presentations of the same damage area are stable and idempotent.
