===================================================================================================
0. EXECUTIVE SUMMARY & THE 1:1 PORT OBJECTIVE
===================================================================================================

The Lil Cu 64 Demoscene application ports the interactive 3D hero stage of `index.html` into a
first-class, native BTRON application (`src/demo/`). It serves as the ceremonial presentation of
B-System Alpha 1, proving the integration of:
1. High-performance OpenGL rendering (TinyGL software rasterizer or VirGL hardware acceleration).
2. Procedural 4D non-Euclidean geometry (Hopf fibration).
3. 60 FPS bipedal mascot kinematics with critically damped inertial springs.
4. An autonomous, assetless procedural sound engine streaming 16-bit 44.1kHz stereo PCM directly to
   VirtIO sound hardware.

By adhering to the "Audio-Visual Shim Principle" established in `SOUND.txt`, every visual action of
Lil Cu 64 phase-locks directly into synthetic acoustic waves, eliminating external asset dependencies.

3. BACKGROUND 4D HOPF FIBRATION ENGINE (MATHEMATICAL FORMALIZATION)
===================================================================================================

3.1 4D Hyperspherical Coordinate Mapping on S³
The Hopf fibration maps the 3-sphere S³ ⊂ ℝ⁴ to the 2-sphere S² ⊂ ℝ³.
Each fiber is a great circle on S³. A family of nested flat tori in S³ is parameterized by:

  η = π/7 + (t + 0.6) * (π / (numTori * 2.8))     for t ∈ [0, numTori - 1]
  β = (f * 2π / fibersPerTorus) + ω               for f ∈ [0, fibersPerTorus - 1]
  ξ = p * 2π / numPts                             for p ∈ [0, numPts]

where:
  ω = time * 0.08 + circularPhase * 0.40
  ψ = time * 0.12 + circularPhase

The 4D coordinates (x₀, x₁, x₂, x₃) on S³ are:
  x₀ = cos(η) * cos(ξ + β/2 + ψ)
  x₁ = cos(η) * sin(ξ + β/2 + ψ)
  x₂ = sin(η) * cos(ξ - β/2 + 0.8 * ψ)
  x₃ = sin(η) * sin(ξ - β/2 + 0.8 * ψ)

3.2 Stereographic Projection S³ → ℝ³
Projecting from the pole (0, 0, 0, 1) into 3-dimensional Euclidean space ℝ³:

  denom = 1.08 - x₃
  X = x₀ / denom
  Y = x₁ / denom
  Z = x₂ / denom

In native OpenGL, (X, Y, Z) are passed directly to `glVertex3f(X, Y, Z)` inside a `GL_LINE_STRIP`,
letting the GPU or TinyGL perform hardware perspective projection and clipping.

3.3 Flywheel Angular Damping & Rainbow Spectral Dispersion
- Inertial Flywheel:
    circularVelocity *= 0.968
    circularPhase += circularVelocity
- Rainbow Dispersion:
  Each fiber loop calculates its hue dynamically:
    hue = ((fiberIdx / totalFibers) * 360.0 + time * 24.0) % 360.0
  and converts HSV (hue, 0.95, 0.85) to standard OpenGL RGB via `glColor3f(r, g, b)`.

3.4 Spherical Radiant Wave (Journey Sacred Wave Dynamics)
When triggered, a dual-tier radiant wave expands outward:
- Radius: r(t) = 0.5 + (1 - (1 - t/T)^2.8) * (R_max - 0.5)
- Tier 1: Inner luminous celestial blue dome veil.
- Tier 2: Outer golden crest ring + turquoise resonance rim with stardust markers.

4.2.1 Critically Damped Harmonic Oscillator Differential Equations
Between any animation state transitions, every state parameter x_i(t) evolves toward its target
pose goal x*_i(t) governed by the 2nd-order non-linear differential equation:

  d²x_i/dt² + 2·ζ·ω_i · (dx_i/dt) + ω_i² · (x_i(t) - x*_i(t)) = 0

where:
  ζ = 1.0 (Exact Critical Damping — zero overshoot, zero mechanical jerk, C∞ continuity)
  ω_i = Natural angular frequency [rad/s]

In discrete real-time simulation (dt = 0.0166s / 60 FPS), this integrates into the frame-rate
independent exponential relaxation formula:

  x_i(t + dt) = x*_i(t) + (x_i(t) - x*_i(t)) · e^(-k_i · dt)

with tuned stiffness constants:
  k_pos   = 18.0 s⁻¹  (Root & body translations)
  k_rot   = 16.0 s⁻¹  (Torso & root angular rotations)
  k_scale = 22.0 s⁻¹  (Volumetric squash & stretch response)
  k_hand  = 15.0 s⁻¹  (Limb gestures)
  k_foot  = 20.0 s⁻¹  (Bipedal footfalls)
  k_mouth = 24.0 s⁻¹  (Facial expression morphs)

6. PROCEDURAL DSP AUDIO ENGINE & VIRTIO SOUND STACK
===================================================================================================

6.1 0-Byte Footprint Audio Philosophy
In compliance with `SOUND.txt`, no sample files (WAV, AIFF, OGG) exist in the repository. Audio is
computed entirely in software at 44,100 Hz stereo 16-bit PCM.

6.2 The Sound Shim Library
Each shim is an analytical DSP function:
- `shimPulseSquash`: 6-harmonic ascending additive sine wave with fast attack and exponential decay.
- `shimFrogCroak`: Dual-oscillator (sawtooth + triangle) pitch scoop passed through a 2.2x formant
  bandpass filter with a 32 Hz amplitude modulation pulse train.
- `shimPulseBell`: 2-operator frequency modulation: carrier = f, modulator = 2.76 * f, index = 1.8.
- `shimWaddle`: Dual triangle bass oscillators with 180 Hz 2-pole lowpass filter and body decay.
- `shimFloat`: 4-note rolling chord additive Fender Rhodes synthesis with resonant tine pings.
- `shimDance`: Rapid 16th-note star arpeggios cascading over modal scales.
- `shimDing`: Pure high sine chime (A6 1760 Hz / E7 2637 Hz) with 0.70s exponential decay.
- `shimKick`: Exponential pitch drop (120 Hz -> 45 Hz) in 160ms with punch envelope.
- `shimSnare`: Triangle tone burst (175 Hz) blended with bandpass-filtered white noise.
- `shimHiHat`: Highpass filtered (7.5 kHz) white noise with 40ms decay.
- `shimGrandPiano`: Triple detuned harmonic sines with physical felt hammer transient.
- `shimIndustrialBass`: Overdriven 16th-note sawtooth waves with soft saturation clipping.
- `shimSwarmatron`: Clustered 8-voice micro-detuned oscillators with continuous ribbon pitch glissando.
