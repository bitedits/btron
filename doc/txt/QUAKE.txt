0. ARCHITECTURAL TENETS
=============================================================================

1. On-Demand Launch Policy:
   Quake does NOT open on system boot. The user launches it from gterm:
       [BTRON3 /SYS]% quake
   This invokes clu_quake(), prints diagnostics, calls open_quake_window().

2. Windowed BTRON Desktop Integration:
   Quake runs inside a native WND with titlebar, border, close, and resize.
   The compositor drives paint via quake_paint(). ESC or close button shuts
   down the render task cleanly via s_shutdown_req signalling.

3. Dual-Backend Graphics:
   - GLES 1.1 / TinyGL / virgl  (Active) : software + QEMU GPU
   - Vulkan 1.2 / Venus           (Phase 7): POSIX host + VirtIO-GPU Venus

4. NASA JPL Rule 3 — Zero Heap:
   All engine memory is a 64 MiB static BSS hunk arena (s_hunk_buffer).
   No malloc/free/realloc after init. RGBA scratch for textures is a
   1 MiB static BSS buffer (s_rgba_scratch), not hunk-allocated.

5. T-Kernel Task Scheduler:
   A 60 FPS animation task (cre_tsk/sta_tsk) calls inval_wnd() in a loop.
   On window close, s_shutdown_req=1 signals the task; it calls
   Quake_Shutdown() and exits cleanly. No wup_tsk race conditions.

  [x] Fix Black Screen Bug:
      Cause 1: Double World_LoadMap in quake_app.c wiped hunk textures via
               Hunk_FreeToLowMark rollback. Fixed by removing redundant load.
      Cause 2: spawn_origin had oz+24.0f, and SV_ServerFrame added another

               alias model call. Added NULL pointer safety checks.
      Cause 4: glColor4f in r_part.c replaced with glColor3f alpha modulation
               to match gl_dispatch table.

4. MEMORY BUDGET (64 MiB HUNK)
=============================================================================

  PAK image (pak0.pak, zero-copy)  ~18.6 MB  hunk (Hunk_AllocName)
  Entity string copy (e1m1)          ~50 KB   hunk (Hunk_Alloc)
  MDL frame vertex arrays            ~2–4 MB  hunk (per model × numframes)
  progs.dat image                    ~500 KB  hunk (FS_LoadFile)
  ─────────────────────────────────────────────────────────────────
  Total in hunk                    ~23 MB  / 64 MB  (36% used, 41 MB free)

  BSS (outside hunk):
  s_rgba_scratch[512×512×4]          1 MB   BSS (texture decode scratch)
  g_gl_textures[512×52 bytes]       26 KB   BSS (texture descriptor table)
  g_alias_models[64]               ~32 KB   BSS (model descriptors)
  g_prvm.edicts[600×EDICT_FIELDS]  ~300 KB  BSS (entity field table)
  s_hunk_buffer[64 MiB]            64 MB    BSS (the hunk itself)

6. LAUNCH WORKFLOW
=============================================================================

1. Boot: B-System opens desktop accessories. Quake NOT started.
2. User opens GTerm.
3. User types: quake
4. clu_quake() prints:
     Quake 3D for B-System (OpenGL ES 1.1 / TinyGL & VirtIO-GPU):
       Version  : 1.09 (Cleanroom Port, Phase 5)
       Map      : maps/e1m1.bsp (The Slipgate Complex)
       Asset    : assets/quake/pak/pak0.pak (18.6 MB, E1M1)
       Renderer : OpenGL ES 1.1 (VirtIO-GPU 3D / TinyGL fallback)
5. open_quake_window(120, 60, 480, 360) creates WND.
6. FS_Init(), R_Init(), World_LoadMap("maps/e1m1.bsp") execute once.
7. 60 FPS T-Kernel task drives inval_wnd() → quake_paint() → R_RenderView().
8. Closing window or pressing ESC: s_shutdown_req=1 → task exits →
   Quake_Shutdown() zeroes g_bsp_cache → ready for relaunch.
