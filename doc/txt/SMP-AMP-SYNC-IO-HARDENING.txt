1. INTRODUCTION & GOALS
==============================================================================

B-System concurrency is deliberately Erlang/BEAM-style actors in pure C99
(Zero-Switch Actor Topology) rather than classic synchronous RPC/microkernel
IPC. The real-time audio path (VirtIO-Sound, Cassette, Orchestra) and any
future GStreamer/PipeWire-style media plane sit on top of this foundation.

Hardening order is therefore:

  ASYN (actor / MPSC / InterCore)  →  SMP (multi-core isolation)
  →  AMP (single dedicated I/O core)  →  media-plane expansion.

This document is the single plan that binds:

  • SMP.md          — Tier-1 unicore vs Tier-2 SMP, MPSC, PML4/PCID, DP policy
  • ASYNC.txt       — equal-priority INPUT/UI planes, periods, budgets, InterCore
  • IO.txt          — exactly one I/O core, release/takeover, SPSC EVT, prohibitions
  • platform.rs     — AMP, CAS multicursor sectors, InterCore (pub/sub/spawn/snd/rcv),
                      Ractors (Task/Timer/IO), zero-copy, static affinity

Goal: make the actor substrate deterministic, lock-free, allocation-free on
critical paths, and verifiable by a single conformance harness (test-asyn)
before any further media-plane investment.

6. PHASES
==============================================================================

6.1  Phase 0 — Baseline & Measurement
-------------------------------------
Targets: posix + uefi
• Instrument MPSC enqueue/dequeue latency and drop rates under load.
• Simple stress harness (concurrent producers + light audio + TAD + windowing).
• Document current WCET bounds (message → worker → VirtIO-Sound write).
• Confirm make run-posix and make run-uefi are the daily loops.
Deliverable: measured maxima table → choose latency budgets for later phases.

6.2  Phase 1 — ASYN / MPSC / InterCore
-------------------------------------
Primary: posix → qemu / sakamura
• Lock-free correctness (memory ordering, ABA, overflow policy).
• Bounded static message pools (NASA JPL Rule 3 style).
• Priority / affinity hooks so Orchestra / Cassette can pin real-time workers.
• Leaky / drop policy consistent with GST.md-style queues.
• Implement InterCore surface (pub/sub/spawn/snd/rcv) on top of MPSC.
• Non-blocking drain loop robust under overload.
Success: deterministic sub-ms message delivery on posix and qemu under
         concurrent audio + UI load; make test-asyn --mode=mpsc,intercore green.

6.3  Phase 2 — SMP Core Hardening
---------------------------------
Primary: uefi (x86_64-uefi-smp)
Secondary: arm64-elf (Pi 4B)
• Stabilise AP rendezvous (INIT-SIPI-SIPI, trampoline @ 0x9000, per-CPU stacks).
• CR3 / PCID switching and TLB behaviour.
• Shared kernel high-half + per-process user space isolation.
• Keep Display Primitives (DP) in Ring 0 / shared mapped buffers
  (avoid NT 3.51 graphics tax).
• Explicit core affinity for media tasks.
Success: multi-core Orchestra + Cassette + TAD workloads without priority
         inversion or unbounded latency on uefi.

6.4  Phase 3 — AMP I/O Core (IO.txt)
------------------------------------
Primary: arm64 (Pi 4 / Pi 400) then uefi simulation
• Exactly one I/O core (default ASYNC_IO_CORE_ID = 3).
• Release word + heartbeat (≤ 50 ms) + takeover handshake (BR1–BR5).
• EVT queue converted to wait-free SPSC; single-producer invariants enforced.
• I/O-core prohibitions: no mailbox, no uart, no heap, no full paint.
• Absolute-deadline loop @ 250 µs, WCET budget 500 µs.
• Fallback path when I/O core never starts (core 0 cooperative path still works).
Success: make test-asyn --mode=amp green; dual-producer windows == 0.

6.5  Phase 4 — Cross-Port Validation
------------------------------------
• arm-elf / Pi 2B: prove ASYN still meets hard RT bounds with flat address
  space and zero MMU (Tier-1).
• sakamura + qemu: full T-Kernel + VirtIO integration.
• Re-run conformance / stress suite on all P0–P2 targets.
• Only then bring P3/P4 ports up to the same bar.

6.6  Phase 5 — Media Plane Expansion (deferred)
-----------------------------------------------
• Extend Orchestra’s zero-dep C99 GStreamer pipeline with confidence.
• Optional constrained GStreamer subset or thin PipeWire-like node graph
  mapped onto the hardened ASYN workers.
• Multi-app mixing, WebRTC-style MCU (GST.md patterns), recording, etc.
Do not start until Phases 0–4 are green.

7.1  Coverage Map
-----------------
Document          | Key invariants exercised by test-asyn
------------------|-------------------------------------------------------------------
SMP.md            | Tier-1 vs Tier-2; lock-free MPSC; Zero-Switch Actor Topology;
                  | shared kernel high-half; PCID/CR3 on UEFI; DP out of user IPC
ASYNC.txt         | Equal pri INPUT/UI; fixed periods + budgets; bounded ISR/polling;
                  | wait-free pointer snapshot; gated MOVE; InterCore mapping;
                  | elimination of “USB progress only inside paint”
IO.txt (AMP)      | Exactly one I/O core; release/takeover; SPSC EVT; single-producer
                  | (xHCI, pointer_slot, EVT); I/O-core prohibitions; absolute
                  | deadline + WCET budget; heartbeat / fallback
platform.rs       | AMP affinity; CAS multicursor sectors; InterCore pub/sub/spawn/
                  | snd/rcv; Ractor isolation; zero-copy; star topology of publishers

7.2  Modes
----------
--mode=mpsc        pure CAS MPSC (SMP.md §3 + platform.rs multicursor)
--mode=intercore   full pub/sub/spawn/snd/rcv surface
--mode=planes      ASYNC.txt INPUT/UI equal-pri periods + budgets
--mode=amp         IO.txt single I/O core + release protocol
--mode=reactors    Task/Timer/IO reactor isolation
--mode=full        all of the above + light VirtIO-Sound / Orchestra stub
--mode=unicore     force Tier-1 behaviour (1 core, flat, no AMP)

Common options:
  --cores=N  --producers=M  --duration=S  --msgs=K
  --io-core=3  --period-io-us=250  --budget-io-us=500
  --period-ui-us=8333  --budget-ui-us=4000
  --trb-budget=32  --policy=leaky|drop|block
  --audio=0|1  --verbose=0|1

7.3  InterCore API Surface (normative, identical to platform.rs taxonomy)
------------------------------------------------------------------------
writer_id_t  pub(size_t capacity);              /* publisher CAS cursor   */
reader_id_t  sub(writer_id_t pub);              /* subscriber cursor      */
task_id_t    spawn(core_id_t, program, cursors[]); /* exclusive ownership */
bool         snd(writer_id_t, void *data);      /* non-blocking send      */
bool         rcv(reader_id_t, void *out);       /* non-blocking receive   */

All later modes (planes, amp, full) post events only through this surface.

==============================================================================
8. RULES OF ENGAGEMENT
==============================================================================

1. Daily loop = make run-posix + periodic make run-uefi.
2. Never break the unicore real-time contract on arm-elf / Pi 2B while
   adding SMP/AMP features.
3. All new ASYN/SMP/AMP code stays cleanroom C99 + static allocation on
   critical paths.
4. Makefile targets stay as they are; only add test-asyn* targets.
5. Document every latency bound and isolation guarantee (extend SMP.md
   or add ASYN.md).
6. InterCore is the only permitted cross-core primitive on the ASYNC path.
7. Exactly one I/O core; never share the input workload across cores.
8. Media-plane (GStreamer subset, PipeWire-like graph, WebRTC MCU) work
   is forbidden until Phases 0–4 are green.


==============================================================================
9. SUCCESS CRITERIA SUMMARY
==============================================================================

• make test-asyn green on posix, qemu, sakamura, uefi, arm64.
• MPSC / InterCore: perfect accounting, sub-ms latency, zero post-boot alloc.
• Planes: max pointer-snapshot gap ≤ 2×Ti under continuous dirty UI.
• AMP: dual-producer windows == 0, release/takeover/heartbeat OK,
  I/O-core prohibitions held, WCET ≤ budget.
• Unicore (Tier-1) path still meets hard RT bounds.
• Only then open Phase 5 (media plane).
