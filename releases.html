第1部：B-System Alpha 1「Ceremony」公式リリース
Part 1 — Official Announcement: B-System Alpha 1 ("Ceremony")

「初めてマシンに火を入れる瞬間は、賭け事ではなく厳粛な儀式であるべきだ —— スキー・ブートローダーはすべての起動を意図的で、美しき所作へと昇華させる。」
"The first time you turn on a machine should feel like a ceremony, not a gamble — Bootloader makes every boot a deliberate, beautiful act."

Synrc Research Centerは、B-System Alpha 1（バージョン 3.20-alpha.1、コードネーム「Ceremony」）の正式公開をお知らせします。 B-Systemは、日本のパーソナルコンピュータ規格の金字塔であるBTRON3 SPEC 3.20仕様に準拠したクリーンルーム再構築OSです。標準C99で設計され、坂村健博士とTRONプロジェクトが提唱した直感的な造形美、リアルタイム応答性、そして実身・仮身ハイパーデータ構造を現代のオープンソース環境に甦らせます。

Alpha 1 の主な機能と到達点（Release Highlights）

25日間にわたる集中的なシステム開発を結実させ、単一コードベースから完全に再現可能なリリースパッケージを構築しました：

  • 7大ハードウェア＆ハイパーバイザー統合対応： 単一のBSD Makefileから、開発ホスト（macOS/Linux POSIX）、ARM QEMU VirtIO、Raspberry Pi 2B実機ベアメタル、坂村T-Kernel 2.0、x86_64 UEFI SMPマルチコアワークステーション、NEC PC-9801/PC-9821 VM、そして64ビットAArch64 Raspberry Pi 4Bまでを統合起動。
  • ダイレクトMultiboot単一段階ローディング： 脆弱な2段階MBR/VBRチェーンローダーを撤廃し、Multiboot 1ヘッダー（0x1BADB002）によりファームウェア／QEMUから1MB空間へ直接展開。
  • 本物の「実身／仮身」ハイパーデータエンジン： 文書内にキャビネット内の実身（Real Body）へのポインタ（仮身・Virtual Body）を無制限に埋め込める坂村ハイパーメディア構造を忠実に実装。
  • Mozc TIPネイティブ日本語入力環境＆チベット語入力： Google Mozcのかな漢字変換エンジン（mozc_kkc.c）、TRON Text Input Primitives（TIP/IFE）、およびチベット文字EWTS Wylie入力メソッド・形態素辞書を内蔵。
  • 15種のコンシューマアプリ＆10種の設定パネル： ワークベンチ、端末（gterm）、コマンダー、電卓、時計、環境設定（10大アプレット）、ブートマネージャ（🎿）、Editor、Clarity、Notebook、Review、ブラウザ、メール＆チャット（XMPP）、Cassette（3ヘッドHi-Fiデッキ）、ペイント、管弦楽・MIDI演奏ワークステーション（Orchestra）の全15アプリを完備。
  • 4大公式TAD電子書籍を標準同梱： BTRON3仕様書、T-Kernel 2.0、B-Free OS（1994年）、B-System（2026年）の全4冊を同梱。Elixirバッチコンパイラ（html2tad.exs）により111仕様文書からバイナリTAD（.tad）を自動生成。
  • 適合性テスト90%合格： 370項目（全410検証項目中90.2%）の仕様要件およびシステムコールが自動検証スイートで完全通過。未実装サブシステムはE_NOSPTを誠実に返し、仕様境界を明示。

対応カーネル一覧と先駆者トリビュート（12 Unified Targets & Pioneer Tributes）

Alpha 1では、日本の組み込みリアルタイムOSおよびシステムプログラミングの道を切り拓いた先駆者たち（高田広章、常田浩、横林貴広、坂村健、内田公太、Awe Morris、横山孝典、板垣史彦、久夛良木健、進藤雅弘、新部裕、本田晋也）への敬意を込め、各ターゲットにその名を冠しています。各カーネルの詳細な機能・アーキテクチャ解説および起動コマンドは、ブートローダー製品ページ（Boot.html）の統合カーネル表にて完全掲載されています。

クイックスタート（Quickstart）

$ git clone https://github.com/bitedits/btron.git && cd btron
$ make run-posix     # POSIX  Cleanroom
$ make run-qemu      # VirtIO Cleanroom
$ make run-sakamura  # VirtIO T-Kernel
$ make run-uefi      # i386 UEFI
$ make run-pc98      # i386 PC-98
$ make run-kernel    # Pi 2B
$ make run-yoko      # Pi 3B
$ make run-yoko4     # Pi 4B
$ make run-mips      # MIPS Workstation
$ make run-ps2       # PlayStation 2
$ make run-foma      # FOMA Mobile UI
$ make all
$ make test
$ make verify

第2部：初コミットからの全開発記録
エンジニアリング・ログ (Development History Log)

B-Systemは、マキシム・ソハツキー（Maxim Sokhatsky / Namdak Tonpa / 5HT）により、2026年8月22日から9月26日までの36日間にわたる集中的な開発スプリントで設計・実装されました。 計631コミット、44セッション（実稼働約228.0時間）にわたり、何もない空のGitツリーから12アーキテクチャ対応の仕様完全準拠OSへと進化を遂げました。


Phase 1 · 構想と仕様策定 (Inception & Specification Architecture)

1. 礎石の敷設 (Laying the Bedrock · Commits 1–84 · Aug 22–24)

Sessions 1–3 · 実動約11.7時間 · +31,991 / -7,205 lines

リポジトリは8月22日深夜のコミット 236bc32 にて初期化。数時間のうちに正規の日本語BTRONヘッダ構造（<btron/btron.h>、types.h、itron.h、dp.h、wnd.h、vobj.h）が確立され、TRON基本データ型（W, H, UW, ID, RECT, COLOR）が定義されました。 8月23日にはカーネルメッセージバス、プロセス管理（kernel/proc, kernel/message）、動的メモリアロケータ、坂村ウィンドウマネージャ（wnd.c）、メニュー、タスクトレイ、Display Primitives（DP）が稼働。同時にBTRON3仕様書のウクライナ語翻訳と詳細用語辞書（glossary.txt）が作成されました。

Phase 4 · 実身・仮身エンジンとTAD電子書籍 (Hyper-Data Engine & 4 Books in Native TAD)

8月29日の9.9時間に及ぶマラソンセッションにて、BTRONの真髄である「実身・仮身（Real Body / Virtual Body）」ハイパーデータエンジン（vobj.c）、キャビネット（CAB）ストレージ、およびTADブラウザを実装。 さらにElixir製バッチコンパイラ（scripts/html2tad.exs）を開発し、106本の仕様書から1MB以上のバイナリTADファイル（.tad）を自動生成。BTRON3仕様書、T-Kernel 2.0、B-Free OS（1994年）、B-System（2026年）の全4冊の電子書籍をシステム内に完全格納しました。

Phase 6 · 適合性認証とRaspberry Pi USB HID (Conformance Audit & Raspberry Pi USB HID)

Phase 7 · UEFI SMP、PC-98、マルチターゲット統合 (The Multi-Target Grand Unification)

国際化とマルチメディアの飛躍的拡張。TRON多言語文字体系（TRON-Code第1面）を拡張し、16×16ドットのチベット文字（U-chen書体）ビットマップフォント（tibetan_fonts.c）、EWTS Wylie入力メソッド（wylie.c）、チベット語形態素辞書、および般若心経チベット語テキストを完全搭載。TIP入力フロントエンドにて英数・かな・カナ・チベット語の即時ローテーションを確立しました。 さらに、SONY TC-K777ESの設計思想を継承した「カセット（Cassette）」ステレオオーディオデッキ（audio_player.c）を実装（3ヘッド・デュアルキャプスタン、Type I-IV磁気テープセレクター、ドルビーB/C NR・HX Pro、物理テープ回転シミュレーション、16セグメントVUメーター）。外観・表示・入力・通信網・音響など10大独立アプレットからなる「環境設定コントロールパネル（Settings Cabinet）」と、Nyan Catアニメーション付きシステム情報ダイアログ（about.c）、TADブラウザの自動改行エンジンを完備しました。

Phase 9 · グローバルメニュー・共通メニューエンジン・レトロアイコン体系 (Global Menu & App Menu Architecture)

Phase 10 · 自動画面キャプチャ・Orchestra演奏サーバー・DocOps大展開 (Headless Capturer & Orchestra Live MIDI Server)

10. 実機フレーム抽出・Orchestra・DocOps自動化 (Automated Screen Capture & Live MIDI Server · Commits 324–348 · Sept 4)

ヘッドレスGDEV描画フレームバッファから透過ウィンドウ境界をピクセルパーフェクトに直接抽出する自動画面撮影ツール（capture_screens.c、raw_to_png.py、populate_doc_screens.py）をパイプライン化。全15大アプリと10設定パネルの透過PNGスクリーンショットおよび孤立メニュー展開画面、Aboutボックスを単一コマンドで抽出・HTML文書へ自動注入するDocOps基盤を確立。 音楽アプリを大規模刷新し、内蔵C99 GStreamerメディアパイプライン（外部依存ゼロ）、32ポートMIDIルーティングマトリクス、SMPTE/MTCマスタークロック、ステージシーン即時切替を備えたプロフェッショナル向け「管弦楽（Orchestra）」ライブMIDI演奏サーバー（orchestra.c）を投入（Apple GarageBand / Logic Pro / Avid Pro Toolsに匹敵する確定論的リアルタイム性能）。さらにGeneral Punctuation領域のホモトピー的符号化定理（Theorem 1: $(\phi^{-1} \circ \phi)(S) = S$）を証明・実装し、全約物文字の不可逆化・左亀甲括弧化問題を根本解消しました。

Phase 11 · Raspberry Pi 400実機シリコン＆xHCI USBスタック (Pi 400 Bare-Metal & xHCI Stack)

11. Pi 400一体型キーボード・xHCI・マウス遅延撲滅 (Pi 400 Integrated Keyboard & xHCI · Commits 530–563 · Sept 16–18)

Sessions 37–38 · 実動約26.1時間 · Broadcom BCM2711 Bare-Metal

Broadcom BCM2711を搭載したRaspberry Pi 400実機への完全対応を達成。本体一体型の物理キーボードハードウェアの動作を確立（working keyboard Pi 400）。 さらにxHCI USBホストコントローラスタックを解析・設計（XHCI.txt）し、USBマウスのプロトコルデコードを是正。長年の課題であったポインタ入力バッファのリークと飽和（buffer leaking / buffer compactification）を数学的に解消し、Raspberry Pi 400上での完全な無遅延マウスポインタ操作（Zero-Lag Pointer）を実現しました。

Phase 12 · プリエンプティブ合成エンジン・無遅延ウィンドウ移動・Invalidation API (Compositor Pipeline & Invalidation)

12. 合成パイプライン・スパイク撲滅・Windows 286無効化 (Compositor Pipeline & Smooth Dragging · Commits 564–612 · Sept 19–21)

Sessions 39–41 · 実動約27.0時間 · Graphics & Window Manager Revolution

割り込みやDMAが利用不能な最小環境でも滑らかな60fps描画を維持する「プリエンプティブ・バックバッファリング」（rect union/intersection）を投入。Clipper（矩形クリッピング）、Compositor（半透明プレビュー合成）、Presenter（画面提示）の三段階パイプライン（3bdddb5）を確立しました。 ウィンドウ移動開始時の座標スパイク（跳ね飛び）を完全排除した新ドラッグプロトコル（0bd6a76, 175b2d4）を設計し、移動中のタイトルバー半透明プレビュー、Windows 286着想の無効化（Invalidation）API（3291090）、DMAセルフテスト、およびVideoCore IV/VI GPUハードウェアポーリング最適化（gpu.txt）を完了しました。

Phase 13 · PlayStation 2 (Emotion Engine) 実機稼働・SegUI組込UI・B-Book大体系化 (PS2 GS, SegUI & B-Book)

13. PS2シリコン・SegUIツールキット・B-Book大体系化 (PlayStation 2 GS, SegUI & B-Book Manual · Commits 613–631 · Sept 24–26)

Sessions 42–44 · 実動約8.8時間 · Console Preservation, MCU & Architecture Reference

Sony PlayStation 2（Emotion Engine R5900 64ビットMIPS-III）の完全クリーンルーム移植（core_ps2.c）：GS 4MB eDRAMへのHost-to-Local GIF DMA（ps2_gs_flush）、DualShock 2アナログ速度積分ドライバ（ps2_pad.c）、OHCI USBマウス・キーボード、非破壊カーソル復元（cursor_saved）を完成。 家電・携帯電話・極小組み込み向けゼロヒープUIツールキット「SegUI（セグメンテーションUI）」（include/btron/segui.h, segui.c）を新設。 そしてBeBook着想のB-System公式技術仕様書「B-Book」の全13大サブシステム（新章 fs.html：Chokanji/V1/V2ファイルシステム・SYS/ANDERS/CHOKANJI/NEW-V2ボリューム、および拡張 drivers.html：PCIeデバイスツリー・コンソール保存）の大体系化を完了し、全12大カーネルターゲットを完備しました。
