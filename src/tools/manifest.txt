# assets/msx — B-MSX cartridges, and the C-BIOS they boot under.
#
# A BIN line is a byte-exact copy: the payload's bytes go into one RT_DATABOX record, which is the
# type no text viewer of this system interprets, and the body keeps its host name.  mkbtronfs
# prints how much of the volume is left when it writes this file, and refuses an entry that does
# not fit by naming the blocks it needed.
#
# What is here is what tronMSX can run today: its first cartridge window maps one 32 KiB page at
# 0x4000 and answers MSX_ERR_SIZE above that, so the two MSX1 Lode Runners ship and BULLRUSH,
# NIGHT_RAVEN and NEON_REVENANT wait on the banked megaROM mapper, not on room in the image.  The
# C-BIOS pair is not optional -- the machine has no ROM of its own, and without a BIOS the window
# opens on an empty slot and says so.
DIR "msx" -
FILE "Lode Runner (1984)(Sony)[a].rom"  BIN  "assets/msx/Lode Runner (1984)(Sony)[a].rom"  msx
FILE "Lode Runner II (Japan).rom"       BIN  "assets/msx/Lode Runner II (Japan).rom"       msx
